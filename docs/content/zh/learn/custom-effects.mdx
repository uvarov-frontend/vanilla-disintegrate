自定义效果由两段完整动画组成。Vanilla Disintegrate 提供几何位置、捕获、取消、清理以及音频接入协议；渲染方式和声音都由你选择。

## 使用快照构建粒子效果

下面的完整示例会从 `snapshot` 读取不透明像素，将它们转换为 Canvas 粒子，并让粒子穿过漩涡。快照默认必需，因此特意没有指定 `needsSnapshot`。

<ParticleVortexSource />

将上面的源代码复制到项目中的 `particle-vortex.ts`，再使用与演示完全相同的效果：

```ts
import Disintegrator from 'vanilla-disintegrate/snapdom';

import { particleVortex } from './particle-vortex';

const effects = new Disintegrator();

effects.remove(element, { effect: particleVortex, retain: true });
effects.restore(insertedElement, { effect: particleVortex });
```

<Demo kind="particle-vortex" />

交互演示和代码块使用同一个源文件，因此实现始终可以直接复现。

只有当效果明确使用 DOM、SVG 或其他无需像素的渲染器时，才设置 `needsSnapshot: false`。这会完全跳过该阶段的捕获。

## 动画上下文

工厂会收到 `operation`、真实 `element`、最终 `bounds`、隔离 `layer`、`snapshot`、惰性 `visual`、`AbortSignal`、`random()`、`reducedMotion` 和 `addCleanup(fn)`。

恢复时，`bounds` 描述的是**插入后的新位置**，而不是删除前的位置。

## 返回值

工厂可返回 Web Animation、Promise、`null`，或带 `finished`、`cancel()`、`dispose()` 的控制器。该协议可用于 CSS/WAAPI、Canvas、SVG、WebGL 与第三方引擎。

```ts
const effects = new Disintegrator({
  effects: { vortex: particleVortex },
  effect: 'vortex',
});
```

直接传入效果对象与注册名称使用相同协议。

## 自定义声音

```ts
const effect = defineEffect({
  remove: {
    animate: removeAnimation,
    sound: { src: '/sounds/remove.ogg', gain: 0.35 },
  },
  restore: {
    animate: restoreAnimation,
    sound: ({ signal }) => startMyAudioEngine(signal),
  },
});
```

声音支持 URL、`ArrayBuffer`、`AudioBuffer`、参数对象或播放器工厂。音频错误不会终止视觉或 DOM 操作。
