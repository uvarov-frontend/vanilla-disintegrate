Экспорт по умолчанию — один класс. Он связывает захват, анимацию, звук, сдвиг соседей по layout, фоновую подготовку и хранилище удержанных узлов.

Корневой вход и `/snapdom` заранее регистрируют четыре встроенных эффекта и по умолчанию выбирают `dust`; только `/snapdom` дополнительно предоставляет адаптер захвата. `/core` даёт тот же lifecycle API без эффекта по умолчанию, частиц и встроенных звуков. `/particles` содержит фабрики и определения эффектов, а не класс `Disintegrator`.

## Конструктор

```ts
import Disintegrator from 'vanilla-disintegrate/snapdom';

const effects = new Disintegrator(options);
```

| Опция                  | Тип                                                         | По умолчанию    | Что делает                                                    |
| ---------------------- | ----------------------------------------------------------- | --------------- | ------------------------------------------------------------- |
| `effect`               | `EffectSelection`                                           | `'dust'`¹       | Эффект, если операция не выбрала свой                         |
| `effects`              | `Record<string, EffectDefinition>`                          | `{}`            | Свои эффекты, которые потом выбираются по имени               |
| `sound`                | `boolean \| SoundDefinition`                                | `false`         | `true` играет звуки фаз; определение заменяет их              |
| `layout`               | `boolean \| LayoutOptions`                                  | `true`          | Сдвигает соседей на новые места после удаления                |
| `preparation`          | `boolean \| PreparationOptions`                             | `visible-idle`  | Готовит зарегистрированные элементы в фоне                    |
| `audioPreparation`     | `false \| 'immediate' \| 'idle' \| AudioPreparationOptions` | `'immediate'`   | Готовит только включённый звук; при `sound: false` работы нет |
| `respectReducedMotion` | `boolean`                                                   | `true`          | Пропускает анимацию, если пользователь просил меньше движения |
| `capture`              | `SnapshotCapture`                                           | SnapDOM¹        | Превращает элемент в Canvas                                   |
| `overlayRoot`          | `HTMLElement \| () => HTMLElement`                          | `document.body` | Куда добавляется оверлей анимации                             |
| `zIndex`               | `number`                                                    | `2147483646`    | Слой этого оверлея                                            |
| `random`               | `() => number`                                              | `Math.random`   | Источник сида, вызывается один раз на операцию                |
| `snapdom`              | `SnapdomOptions`                                            | —               | Уходит в `toCanvas()` SnapDOM. Только на входе `/snapdom`     |
| `onTrigger`            | `(context) => void`                                         | —               | После проверок, до начала захвата                             |
| `onStart`              | `(context) => void`                                         | —               | После изменения DOM, в момент старта проигрывания             |
| `onComplete`           | `(context) => void`                                         | —               | После нормального завершения визуальной фазы                  |
| `onError`              | `(error, context) => void`                                  | —               | Ошибки захвата, анимации, звука и колбэков                    |

¹ Значения `dust` и SnapDOM вместе действуют для `/snapdom`; корневой вход предоставляет `dust`, но не захват. `/core` не предоставляет ни того, ни другого.

Для ошибок операций `context.operation` равен `remove` или `restore`. Ошибка фоновой подготовки сообщает `prepare`, поэтому она не маскируется под операцию с контентом.

Фиксированный `random` делает эффект воспроизводимым: один и тот же сид раскладывает частицы одинаково в каждом запуске, что удобно для визуальных регрессионных тестов.

## remove(target, options?)

Измеряет и отсоединяет элемент, синхронно возвращая `EffectOperation`.

```ts
const operation = effects.remove('.card', {
  effect: 'scatter',
  retain: true,
  sound: true,
  layout: { duration: 260 },
  detach: (element) => element.remove(),
});
```

`target` может быть `HTMLElement` или CSS-селектором. Отсутствующий селектор вызывает ошибку до старта операции.

`detach` заменяет стандартный commit через `element.remove()`. Используйте его, когда реактивный рендерер должен удалить узел через собственное состояние. Если callback выбросит ошибку, она попадёт в `onError`, а библиотека безопасно выполнит обычное удаление.

## restore(target, options?)

Анимирует подключённый измеримый элемент в текущей геометрии.

```ts
const operation = effects.restore(element, {
  effect: 'scatter',
  sound: true,
});
```

Отсоединённый элемент или нулевой размер приводят к синхронной ошибке.

## Хранилище

```ts
const element = effects.take(removalId); // HTMLElement | null
const discarded = effects.discard(removalId); // boolean
const count = effects.discardAll(); // number
```

`take()` забирает запись из хранилища. `discard()` и `discardAll()` освобождают ссылки без вставки контента.

## Подготовка снимков

```ts
const unregister = effects.register(elements);
await effects.prepare(elements);
effects.invalidate(elements);
effects.clearPrepared();
```

`register()` следует настроенной стратегии. `prepare()` снимает сразу, даже если фоновая подготовка выключена, и завершается ничем, когда все элементы готовы.

Повторные регистрации одного элемента используют счётчик ссылок: каждая функция отмены освобождает только свою регистрацию, а наблюдение прекращается после освобождения последней.

## Подготовка аудио

```ts
await effects.prepareAudio(['dust', 'wind']);
effects.discardPreparedAudio('dust');
effects.clearPreparedAudio();
```

При `sound: true` на экземпляре стандартный эффект готовится автоматически. Явные методы работают и при выключенном звуке. Декодированные буферы хранятся в ограниченном LRU-кэше.

## destroy()

```ts
effects.destroy();
```

Останавливает операции, observers и фоновые задачи, освобождает владение снимками и декодированным аудио и очищает сохранённые узлы. Общий контекст проигрывания закрывается после уничтожения последнего владеющего им `Disintegrator`. Повторный вызов `destroy()` безопасен; новые операции после уничтожения запрещены.

## EffectOperation

```ts
interface EffectOperation {
  readonly operation: 'remove' | 'restore';
  readonly removalId: RemovalId | null;
  readonly finished: Promise<{
    operation: 'remove' | 'restore';
    status: 'completed' | 'cancelled' | 'skipped' | 'rejected';
    removalId: RemovalId | null;
  }>;
  cancel(): void;
}
```

Объект намеренно не имеет свойства `element` и освобождает ссылку после завершения.

| Статус      | Действие с контентом                          | Когда завершается `finished`        |
| ----------- | --------------------------------------------- | ----------------------------------- |
| `completed` | Выполнено; визуальная фаза завершилась штатно | После очистки визуальных ресурсов   |
| `cancelled` | Выполнено; визуал или звук остановлен         | После очистки при отмене            |
| `skipped`   | Выполнено без доступной визуальной фазы       | После очистки запасного пути        |
| `rejected`  | Не начиналось; DOM не изменялся               | После завершения текущего владельца |

## Колбэки и приоритеты

Колбэки экземпляра выполняются для каждой операции; рядом с ними можно передать колбэки отдельного вызова. Параметры операции перекрывают настройки экземпляра. Эффект, запомненный удержанным узлом, используется в `restore()` только при отсутствии явного `effect`.
