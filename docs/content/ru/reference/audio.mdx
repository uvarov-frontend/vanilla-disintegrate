Звук выключен по умолчанию: передайте `sound: true`, чтобы включить встроенное аудио. Включайте его в обработчике пользовательского действия — браузеры блокируют `AudioContext`, запущенный без жеста. У каждой фазы удаления и восстановления самостоятельное определение аудио: дорожку не нужно разворачивать вместе с анимацией.

## Включение и отключение

```ts
const audible = new Disintegrator({ sound: true });
const silent = new Disintegrator();

effects.remove(element, { sound: true });
```

Настройка операции имеет приоритет для одного вызова.

## Куда класть звук

Звуки лежат в эффекте, по одному на фазу:

```ts
const snap = '/sounds/snap.mp3';

const fold = defineEffect({
  remove: { animate: out, sound: { src: snap } },
  restore: { animate: back, sound: { src: snap, reverse: true } },
});
```

Опция `sound` у экземпляра и у вызова — выключатель для них:

```ts
const effects = new Disintegrator({ effect: fold, sound: true });

effects.remove(card); // играет звук из эффекта
effects.remove(card, { sound: false }); // без звука, анимация та же
```

Одна тонкость. Если передать туда звук вместо `true` или `false`, он ничего не переключит — он заменит звуки в эффекте, и на обе фазы пойдёт один файл:

```ts
new Disintegrator({ sound: { src: '/sounds/snap.mp3' } });
// и удаление, и восстановление проиграют snap.mp3 вперёд
```

Так удобно, когда звук один на всё. Чтобы у удаления и восстановления были разные — задайте их в эффекте.

## Пара для удаления и восстановления

| Что нужно                                  | `remove`        | `restore`                      |
| ------------------------------------------ | --------------- | ------------------------------ |
| Один файл, на восстановлении задом наперёд | `{ src: snap }` | `{ src: snap, reverse: true }` |
| Два разных файла                           | `{ src: out }`  | `{ src: back }`                |
| Звук только при удалении                   | `{ src: snap }` | `null`                         |

Все четыре встроенных эффекта сделаны по первой строке.

## Источники

```ts
type SoundSource = string | URL | ArrayBuffer | AudioBuffer;
```

Строка и `URL` загружаются и декодируются лениво. `ArrayBuffer` подходит при собственном загрузчике ресурсов. `AudioBuffer` удобен, когда приложение уже управляет аудиопайплайном и хочет переиспользовать декодированный звук.

Библиотека не встраивает аудиофайлы в исходный код как `AudioBuffer`: декодирование выполняется браузером, а сжатый файл меньше и хорошо кэшируется.

## Параметры проигрывания

```ts
effects.remove(element, {
  sound: {
    src: new URL('/sounds/snap.ogg', location.href),
    gain: 0.35,
    delay: 40,
    duration: 700,
    fadeDuration: 120,
    playbackRate: 1.05,
  },
});
```

## Проигрывание задом наперёд

Анимация восстановления самостоятельна, но её звук можно проиграть задом наперёд из записи удаления. Тогда один файл закрывает обе фазы, а вторая запись не нужна:

```ts
const remove = { src: '/sounds/snap.mp3' };
const restore = { src: '/sounds/snap.mp3', reverse: true };
```

Так работают все четыре встроенных эффекта.

Реверс переносит громкую часть файла из начала в конец, поэтому вместе с ним меняются ещё две вещи:

- Звук берётся с конца файла, а не с начала. Иначе громкую часть обрезало бы.
- `fadeDuration` даёт нарастание вместо затухания. Иначе фейд пришёлся бы на громкую часть.

Развёрнутая копия делается один раз и остаётся в памяти. Если передать `AudioBuffer`, он копируется — ваш буфер не трогают.

## Пользовательский плеер

```ts
const sound = ({ operation, signal }) => {
  const playback = audioEngine.play(operation === 'remove' ? 'card-out' : 'card-in');

  const stop = () => playback.stop();
  signal.addEventListener('abort', stop, { once: true });

  return {
    finished: playback.finished,
    stop,
    dispose() {
      signal.removeEventListener('abort', stop);
      playback.dispose();
    },
  };
};
```

Фабрика получает тип операции, элемент и `AbortSignal`. Ошибки autoplay, загрузки, декодирования и пользовательского плеера передаются в `onError`, но не прерывают анимацию и выбранное действие с DOM.

## Изоляция ошибок

Ограничения автозапуска, сбои загрузки, ошибки декодирования и исключения в пользовательском плеере никогда не отменяют визуальную операцию только из-за звука. Они уходят в `onError`, а анимация и выбранное действие над DOM продолжаются.
