## [0.1.0] - 2026-08-27

### Added

- DOM-to-particle disintegration powered by SnapDOM and the Web Animations API.
- Smooth FLIP transitions for following siblings and the layout container.
- Viewport-aware idle snapshot preparation with mutation invalidation.
- Optional original synchronized sound through Web Audio.
- Declarative delegated `bind()` integration for vanilla DOM, including dynamic items.
- Reduced-motion support, lifecycle callbacks, and reversible handles.
- ESM, CommonJS, IIFE, zero-dependency core, source maps, and TypeScript declarations.
