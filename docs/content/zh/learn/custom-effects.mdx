自定义效果就是两段动画：一段用于删除元素，一段用于把它放回来。动画和声音由你来写。库负责捕获元素、测量位置，并处理取消和清理。

## 通过游乐场配置粒子

主页上的游乐场会生成完整的自定义效果，并为删除与恢复分别设置粒子和声音。例如，以下代码组合了 `scatter` 删除和 `vapor` 恢复：

```ts
import Disintegrator, { createParticleEffect, particlePresets } from 'vanilla-disintegrate/snapdom';

const sharedSoundOptions = {
  volume: 0.32,
  playbackRate: 1,
  delay: 0,
  fadeDuration: 0.18,
};

export const disintegrator = new Disintegrator({
  effect: createParticleEffect({
    remove: particlePresets.scatter,
    restore: particlePresets.vapor,
  }),
  sound: {
    remove: {
      ...sharedSoundOptions,
      src: 'scatter',
      reverse: false,
    },
    restore: {
      ...sharedSoundOptions,
      src: 'vapor',
      reverse: true,
    },
  },
});
```

`createParticleEffect()` 使用内置粒子渲染器。在游乐场中配置两个阶段并复制生成的代码，无需自行编写 Canvas 或 WebGL 渲染器。只有在需要实现渲染过程本身时，才需要阅读下一节。

所有运动参数、默认值、有效范围和底层阶段工厂请参阅[粒子 API](/zh/docs/reference/particles/)。

## 控制粒子渲染质量

`renderQuality` 独立于捕获适配器，用来控制内置 WebGL 渲染器的分辨率。默认的 `auto` 模式会限制内存和 GPU 开销：渲染器的源纹理最多包含 2,000,000 个像素，单边最多 2,048 像素；扩展动画表面最多包含 4,000,000 个像素。

如果保留捕获快照的完整分辨率比这些软件限制更重要，请使用 `exact`：

```ts
const exactEffect = createParticleEffect({
  remove: { ...particlePresets.vapor, renderQuality: 'exact' },
  restore: { ...particlePresets.scatter, renderQuality: 'exact' },
});
```

也可以自行设置预算：

```ts
const boundedEffect = createParticleEffect({
  remove: {
    ...particlePresets.vapor,
    renderQuality: {
      maxSourcePixels: 4_000_000,
      maxSourceDimension: 4096,
      maxRenderPixels: 8_000_000,
    },
  },
});
```

`exact` 会关闭软件降采样，但无法绕过设备的 WebGL 纹理和视口限制。如果设备无法创建所需的精确表面，错误会通过 `onError` 报告，而不会静默降低质量。对于尺寸未知或较大的元素，建议使用 `auto`；完整分辨率的开销大致随 device pixel ratio 的平方增长。

## 调整 WebGL 上下文上限

```ts
import { configureParticleContexts } from 'vanilla-disintegrate/snapdom';

configureParticleContexts({ maxContexts: 2, maxIdleContexts: 1 });
```

粒子渲染器在整个页面范围内最多同时保留 4 个 WebGL2 上下文，其中最多 2 个会在效果结束后保温以便复用。这个上限是整页共享的，而不是按每个效果单独设置：浏览器本身就限制了一个页面能保留多少活跃上下文，若两个效果各自要求不同的值，也不存在唯一正确的答案。

因页面已达上限而无法获取上下文的效果，走的是与设备完全没有 WebGL2 时相同的路径：`remove()` 仍会移除元素，`restore()` 仍会显示元素。配置了 `fallback` 时会改为运行它；没有时操作以 `skipped` 状态结束，`onError` 收到的是笼统的“未创建动画”错误，并不会指出真正原因是上下文竞争。在任何效果运行之前调用一次 `configureParticleContexts()`，即可在页面的整个生命周期内更改这个上限。在内存受限的设备上调低它；调高时不要超过浏览器自身允许的范围，否则只是把上下文被丢弃的位置往后移。

## 无 WebGL2 的备用效果

对于带有 `requires: 'webgl2'` 的阶段，可以在构造函数中传入包含同一对 `remove`/`restore` 的 `fallback`。它可使用 CSS、Web Animations API、Canvas 2D、SVG 或自定义渲染器，但不能使用 WebGL2。WebGL2 不可用或内置粒子渲染器无法启动时，它都会运行；WebGL2 不可用时，库会在**捕获之前**选择它。它不会播放内置声音。完整契约和示例请参阅 [API](/zh/docs/reference/api/#webgl2-beiyongxiaoguo)。

## 使用无快照核心入口

若两个阶段都设置 `needsSnapshot: false`，请导入 `/core`：捕获适配器、粒子渲染器与内置音频都不会进入模块图。

```ts
import Disintegrator, { defineEffect } from 'vanilla-disintegrate/core';

const fade = defineEffect({
  remove: {
    needsSnapshot: false,
    animate: ({ element, layer }) => {
      const visual = element.cloneNode(true) as HTMLElement;
      Object.assign(visual.style, {
        height: '100%',
        inset: '0',
        margin: '0',
        pointerEvents: 'none',
        position: 'absolute',
        width: '100%',
      });
      layer.append(visual);
      return visual.animate([{ opacity: 1 }, { opacity: 0 }], { duration: 240 });
    },
  },
  restore: {
    needsSnapshot: false,
    animate: ({ element, layer }) => {
      const visual = element.cloneNode(true) as HTMLElement;
      Object.assign(visual.style, {
        height: '100%',
        inset: '0',
        margin: '0',
        pointerEvents: 'none',
        position: 'absolute',
        width: '100%',
      });
      layer.append(visual);
      return visual.animate([{ opacity: 0 }, { opacity: 1 }], { duration: 240 });
    },
  },
});

const effects = new Disintegrator({ effect: fade });
```

## 动画上下文

工厂会收到：

- `operation` — `remove` 或 `restore`
- `element` — 元素本身
- `bounds` — 它在屏幕上的位置，`DOMRectReadOnly`
- `layer` — 一个空的覆盖层，已经摆在这个位置上
- `snapshot` — 捕获到的画布，或 `null`
- `visual` — 画好快照的全尺寸画布，首次访问时才创建
- `signal` — 操作被取消或实例被销毁时触发
- `random()` — 本次操作的随机数，带种子，便于复现
- `reducedMotion` — 工厂运行时始终为 `false`；减少动效请求会在调用工厂前跳过操作
- `addCleanup(fn)` — 放进去的清理逻辑，无论结果如何都会执行

恢复时，`bounds` 描述的是**插入后的新位置**，而不是删除前的位置。

## 返回值

动画工厂可以返回：

```ts
type AnimationResult =
  | Animation
  | PromiseLike<unknown>
  | {
      element?: HTMLElement;
      finished: PromiseLike<unknown>;
      duration?: number;
      layoutDelay?: number;
      cancel?(): void;
      dispose?(): void;
    }
  | null;
```

因此 Web Animation、Promise、Canvas 或 WebGL 循环以及第三方引擎包装器都适用。`cancel()` 停止播放；`dispose()` 无条件释放渲染器资源，无论动画完成、取消还是失败都会执行。

## 创建自己的预设

自定义 `effect` 默认静音。若动画与音频应作为一个完整选项一起复用，请把它们包装成完整预设：

```ts
import { definePreset } from 'vanilla-disintegrate';

const vortex = definePreset({
  effect: particleVortex,
  sound: {
    remove: { src: 'vapor', volume: 0.35 },
    restore: { src: 'vapor', volume: 0.35, reverse: true },
  },
});

const effects = new Disintegrator({
  preset: 'vortex',
  presets: { vortex },
});

effects.remove(element);
```

内置预设名称由根入口与 `/snapdom` 注册。`/core` 只能看到通过 `presets` 提供或通过 `preset` 内联传入的预设。

## 自定义声音

视觉阶段与声音应保持分离。构造器接收独立的 `remove` 和 `restore` 定义；若自定义效果应保持静音，请省略 `sound`。

```ts
const effects = new Disintegrator({
  effect: particleVortex,
  sound: {
    remove: { src: '/sounds/remove.ogg', volume: 0.35 },
    restore: ({ signal }) => startMyAudioEngine(signal),
  },
});
```

`src` 还支持内置名称、`URL`、本地 `Blob`/`File`、`ArrayBuffer`、typed-array view 或 `AudioBuffer`。音频错误会传给 `onError`，但动画与 DOM 变更会继续执行。
