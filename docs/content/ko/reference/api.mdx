`Disintegrator`는 하나의 완전한 시각 설정, 선택적 오디오, 캡처, 레이아웃 애니메이션, 백그라운드 준비와 보관 노드 저장소를 연결합니다.

루트 및 `/snapdom` 엔트리는 완성된 내장 프리셋 네 개를 등록하며 `/snapdom`만 캡처 어댑터를 제공합니다. `/core`는 내장 프리셋, 파티클, 사운드와 캡처 없이 수명 주기만 제공합니다. 어떤 엔트리도 기본 프리셋을 선택하지 않습니다.

## 생성자

```ts
import Disintegrator, { createParticleEffect } from 'vanilla-disintegrate/snapdom';

const ready = new Disintegrator({ preset: 'dust' });
const custom = new Disintegrator({ effect: createParticleEffect() });
```

`preset`과 `effect` 중 정확히 하나가 필요합니다.

```ts
type DisintegratorOptions =
  | { preset: PresetSelection; effect?: never; sound?: false }
  | { preset?: never; effect: EffectDefinition; sound?: false | SoundSelection };
```

프리셋은 시각 효과와 오디오를 합친 원자적 선택입니다. `sound: false`로 음소거할 수 있지만 다른 시각 효과나 대체 오디오와 조합할 수 없습니다. 사용자 효과는 완전한 `remove` 및 `restore` 단계를 가진 객체이며 사운드 쌍을 제공하지 않으면 무음입니다.

공통 옵션:

| 옵션                   | 타입                                                        | 기본값          | 역할                                               |
| ---------------------- | ----------------------------------------------------------- | --------------- | -------------------------------------------------- |
| `presets`              | `Record<string, PresetDefinition>`                          | `{}`            | `preset`으로 선택할 완성된 사용자 프리셋을 추가    |
| `layout`               | `boolean \| LayoutOptions`                                  | `true`          | 삭제 후 이웃 요소를 새 위치로 이동                 |
| `preparation`          | `boolean \| PreparationOptions`                             | `visible-idle`  | 등록된 요소의 스냅샷을 준비                        |
| `audioPreparation`     | `false \| 'immediate' \| 'idle' \| AudioPreparationOptions` | `'idle'`        | 준비와 디코딩 오디오 소유권 예산을 제어            |
| `respectReducedMotion` | `boolean`                                                   | `true`          | 사용자가 모션 감소를 요청하면 애니메이션을 건너뜀  |
| `capture`              | `SnapshotCapture`                                           | SnapDOM¹        | 스냅샷 기반 효과를 위해 요소를 canvas로 변환       |
| `overlayRoot`          | `HTMLElement \| () => HTMLElement`                          | `document.body` | 고정 위치 애니메이션 오버레이를 받음               |
| `zIndex`               | `number`                                                    | `2147483646`    | 오버레이 스택 레벨을 설정                          |
| `random`               | `() => number`                                              | `Math.random`   | 작업마다 재현 가능한 의사 난수 스트림을 초기화     |
| `snapdom`              | `SnapdomOptions`                                            | —               | SnapDOM의 `toCanvas()` 설정, `/snapdom`에서만 사용 |
| `onTrigger`            | `(context) => void`                                         | —               | 검증 뒤 캡처 전에 실행                             |
| `onStart`              | `(context) => void`                                         | —               | DOM 변경 뒤 재생이 시작될 때 실행                  |
| `onComplete`           | `(context) => void`                                         | —               | 시각 단계가 정상적으로 끝난 뒤 실행                |
| `onError`              | `(error, context) => void`                                  | —               | 격리된 캡처, 애니메이션, 사운드와 콜백 오류를 받음 |

¹ SnapDOM은 `/snapdom`에서만 기본값입니다. 선택한 효과에 스냅샷이 필요하면 루트 및 `/core` 엔트리에 `capture`를 제공해야 합니다.

백그라운드 스냅샷 오류는 `context.operation === 'prepare'`를, 작업 오류는 `remove` 또는 `restore`를 보고합니다.

## 완성된 프리셋

```ts
import Disintegrator, { createParticleEffect, definePreset } from 'vanilla-disintegrate/snapdom';

const dissolve = definePreset({
  effect: createParticleEffect({
    remove: { curve: 'float' },
    restore: { curve: 'settle' },
  }),
  sound: {
    remove: { src: '/audio/out.ogg', volume: 0.4 },
    restore: { src: '/audio/in.ogg', volume: 0.4 },
  },
});

const effects = new Disintegrator({
  preset: 'dissolve',
  presets: { dissolve },
});
```

`definePreset()`은 프리셋, 시각 단계와 네이티브 사운드 옵션 객체를 동결하지만 호출자가 소유한 바이너리 오디오 데이터는 동결하지 않습니다.

## remove(target, options?)

해석된 요소를 분리하고 `EffectOperation`을 동기적으로 반환합니다.

```ts
const operation = effects.remove('.card', {
  preset: 'scatter',
  sound: false,
  retain: true,
  layout: { duration: 260 },
  detach: (element) => element.remove(),
});
```

`target`은 `HTMLElement` 또는 선택자 문자열입니다. 선택자를 찾지 못하면 작업 시작 전에 오류를 던집니다.

`detach`는 기본 `element.remove()` 커밋을 대체합니다. 반응형 렌더러가 자체 상태로 노드를 제거해야 할 때 사용하세요. 콜백이 오류를 던지면 `onError`로 전달하고 네이티브 제거를 안전한 폴백으로 사용합니다.

## restore(target, options?)

연결되고 측정 가능한 요소를 현재 지오메트리에서 애니메이션합니다.

```ts
const operation = effects.restore(element, {
  preset: 'scatter',
  sound: false,
});
```

요소가 분리됐거나 너비 또는 높이가 0이면 오류를 던집니다.

두 작업 모두 하나의 완성된 `preset`, 해당 단계의 선택적 사운드 정의와 함께 사용자 `effect`, 또는 아무것도 전달하지 않아 인스턴스나 보관 노드의 표현을 상속할 수 있습니다. 상속 오디오와 프리셋 오디오는 `sound: false`로만 음소거할 수 있습니다.

## 보관 요소

```ts
const element = effects.take(removalId); // HTMLElement | null
const discarded = effects.discard(removalId); // boolean
const count = effects.discardAll(); // number
```

`take()`은 저장 항목을 소비합니다. `discard()`와 `discardAll()`은 콘텐츠를 삽입하지 않고 참조를 해제합니다.

## 스냅샷 준비

```ts
const unregister = effects.register(elements);
await effects.prepare(elements);
effects.invalidate(elements);
effects.clearPrepared();
```

`register()`는 설정된 전략을 따릅니다. 백그라운드 준비가 꺼져 있어도 `prepare()`는 즉시 캡처합니다. 같은 요소의 반복 등록은 참조 카운트를 사용하며 각 해제 함수는 자신의 등록만 해제합니다.

## 오디오 준비

```ts
await effects.prepareAudio({
  remove: { src: 'dust' },
  restore: { src: 'dust', reverse: true },
});
effects.discardPreparedAudio();
effects.clearPreparedAudio();
```

인수가 없으면 `prepareAudio()`와 `discardPreparedAudio()`는 인스턴스에 설정한 사운드 쌍을 사용합니다. 자동 준비가 꺼져 있어도 명시적 메서드는 동작합니다. 디코딩 버퍼는 제한된 인스턴스 소유권 LRU를 사용하고 요청, 버퍼와 `AudioContext`는 인스턴스 간 공유합니다.

## destroy()

```ts
effects.destroy();
```

활성 작업을 취소하고 관찰자와 백그라운드 작업을 중지하며 스냅샷과 디코딩 오디오 소유권을 해제하고 보관 노드를 비웁니다. 마지막 소유자가 파괴되면 공유 재생 컨텍스트가 닫힙니다. `destroy()`를 반복 호출해도 안전하며 이후 새 작업을 시작하면 오류를 던집니다.

## EffectOperation

```ts
interface EffectOperation {
  readonly operation: 'remove' | 'restore';
  readonly removalId: RemovalId | null;
  readonly finished: Promise<{
    operation: 'remove' | 'restore';
    status: 'completed' | 'cancelled' | 'skipped' | 'rejected';
    removalId: RemovalId | null;
  }>;
  cancel(): void;
}
```

핸들은 요소를 노출하지 않고 완료된 뒤 참조를 해제합니다.

| 상태        | 콘텐츠 동작                          | `finished` 완료 시점  |
| ----------- | ------------------------------------ | --------------------- |
| `completed` | 커밋됨, 시각 단계가 정상적으로 완료  | 시각 정리 후          |
| `cancelled` | 커밋됨, 시각 또는 오디오 재생이 중지 | 취소 정리 후          |
| `skipped`   | 실행 가능한 시각 단계 없이 커밋      | 폴백 정리 후          |
| `rejected`  | 시작하지 않음, DOM이 변경되지 않음   | 현재 소유자가 끝난 뒤 |

## 콜백과 우선순위

인스턴스 콜백은 모든 작업에 실행되고 작업 콜백은 그와 함께 실행됩니다. 명시적 작업 표현, 보관 노드가 기억한 표현, 인스턴스 설정 순서로 우선합니다. 이미 사용 중인 요소에 대한 동시 호출은 현재 소유자가 끝난 뒤 `rejected`로 완료됩니다.
