Свой эффект — это две анимации: одна на удаление элемента, вторая на его возврат. Анимацию и звук пишете вы. Библиотека снимает элемент, измеряет его и берёт на себя отмену и уборку.

## Эффект из снимка и частиц

Пример ниже берёт непрозрачные пиксели из `snapshot`, превращает их в Canvas-частицы и ведёт через вихрь. Пиксели ему нужны, а снимок делается по умолчанию, поэтому `needsSnapshot` в нём и нет.

<ParticleVortexSource />

Скопируйте исходник в проект как `particle-vortex.ts`, затем подключите тот же эффект, который работает в демо:

```ts
import Disintegrator from 'vanilla-disintegrate/snapdom';

import { particleVortex } from './particle-vortex';

const effects = new Disintegrator({ effect: particleVortex });

effects.remove(element, { retain: true });
effects.restore(insertedElement);
```

<Demo kind="particle-vortex" />

Демо выше и блок кода взяты из одного файла, так что работает ровно то, что вы видите.

`needsSnapshot: false` подходит эффекту, который анимирует DOM, SVG или что-то ещё, чему пиксели не нужны. Тогда для этой фазы захвата не будет вовсе.

## Лёгкий вход без снимков

Если обе фазы задают `needsSnapshot: false`, импортируйте `/core`: адаптер захвата, рендерер частиц и встроенное аудио не попадут в граф модулей.

```ts
import Disintegrator, { defineEffect } from 'vanilla-disintegrate/core';

const fade = defineEffect({
  remove: {
    needsSnapshot: false,
    animate: ({ element, layer }) => {
      const visual = element.cloneNode(true) as HTMLElement;
      Object.assign(visual.style, {
        height: '100%',
        inset: '0',
        margin: '0',
        pointerEvents: 'none',
        position: 'absolute',
        width: '100%',
      });
      layer.append(visual);
      return visual.animate([{ opacity: 1 }, { opacity: 0 }], { duration: 240 });
    },
  },
  restore: {
    needsSnapshot: false,
    animate: ({ element, layer }) => {
      const visual = element.cloneNode(true) as HTMLElement;
      Object.assign(visual.style, {
        height: '100%',
        inset: '0',
        margin: '0',
        pointerEvents: 'none',
        position: 'absolute',
        width: '100%',
      });
      layer.append(visual);
      return visual.animate([{ opacity: 0 }, { opacity: 1 }], { duration: 240 });
    },
  },
});

const effects = new Disintegrator({ effect: fade });
```

## Контекст анимации

Фабрика получает:

- `operation` — `remove` или `restore`
- `element` — сам элемент
- `bounds` — где он на экране, как `DOMRectReadOnly`
- `layer` — пустой оверлей, уже поставленный поверх этих границ
- `snapshot` — снятый канвас или `null`
- `visual` — канвас в полный размер с нарисованным снимком, создаётся при первом обращении
- `signal` — сработает при отмене операции или уничтожении экземпляра
- `random()` — случайные числа для этой операции, с сидом, чтобы прогон можно было повторить
- `reducedMotion` — всегда `false` внутри запущенной фабрики; запрос на уменьшение движения пропускает операцию до её вызова
- `addCleanup(fn)` — что сюда положите, выполнится при любом исходе

При восстановлении `bounds` — это **новое** место, куда вы вставили элемент, а не то, откуда его удалили.

## Допустимые результаты

Фабрика анимации может вернуть:

```ts
type AnimationResult =
  | Animation
  | PromiseLike<unknown>
  | {
      element?: HTMLElement;
      finished: PromiseLike<unknown>;
      duration?: number;
      layoutDelay?: number;
      cancel?(): void;
      dispose?(): void;
    }
  | null;
```

Так подойдёт и Web Animation, и промис, и цикл на Canvas или WebGL, и обёртка над чужим движком. `cancel()` останавливает проигрывание. `dispose()` освобождает то, что выделил ваш рендерер, и вызывается независимо от того, доиграла анимация, была отменена или упала.

## Переиспользуемый пресет

Пользовательский `effect` по умолчанию бесшумный. Если анимация и аудио должны использоваться вместе как один готовый выбор, объедините их в полный пресет:

```ts
import { definePreset } from 'vanilla-disintegrate';

const vortex = definePreset({
  effect: particleVortex,
  sound: {
    remove: { src: 'vapor', volume: 0.35 },
    restore: { src: 'vapor', volume: 0.35, reverse: true },
  },
});

const effects = new Disintegrator({
  preset: 'vortex',
  presets: { vortex },
});

effects.remove(element);
```

Имена встроенных пресетов зарегистрированы в корневом входе и `/snapdom`. `/core` видит только пресеты, переданные через `presets` или инлайном через `preset`.

## Свой звук

Храните звук отдельно от визуальных фаз. Конструктор принимает независимые определения `remove` и `restore`; не передавайте `sound`, если пользовательский эффект должен быть бесшумным.

```ts
const effects = new Disintegrator({
  effect: particleVortex,
  sound: {
    remove: { src: '/sounds/remove.ogg', volume: 0.35 },
    restore: ({ signal }) => startMyAudioEngine(signal),
  },
});
```

`src` также принимает встроенное имя, `URL`, локальный `Blob`/`File`, `ArrayBuffer`, typed-array view или `AudioBuffer`. Если звук не сложился, ошибка уходит в `onError`, а анимация и изменение DOM продолжаются.
