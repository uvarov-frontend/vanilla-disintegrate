사용자 효과는 애니메이션 두 개입니다. 하나는 요소를 지울 때, 하나는 되돌릴 때 씁니다. 애니메이션과 사운드는 직접 작성합니다. 라이브러리는 요소를 캡처하고 위치를 재며, 취소와 정리를 맡습니다.

## 스냅샷으로 파티클 효과 만들기

아래 예제는 `snapshot`에서 불투명 픽셀을 읽어 Canvas 파티클로 바꾸고 소용돌이를 따라 움직입니다. 그 픽셀이 필요하고 스냅샷은 기본으로 찍히므로, 예제에 `needsSnapshot`이 없습니다.

<ParticleVortexSource />

위 소스를 프로젝트의 `particle-vortex.ts`로 복사한 뒤, 데모와 동일한 효과를 사용하세요.

```ts
import Disintegrator from 'vanilla-disintegrate/snapdom';

import { particleVortex } from './particle-vortex';

const effects = new Disintegrator({ effect: particleVortex });

effects.remove(element, { retain: true });
effects.restore(insertedElement);
```

<Demo kind="particle-vortex" />

위 데모와 코드 블록은 같은 파일에서 나옵니다. 돌아가는 그대로가 여러분이 가져가는 것입니다.

`needsSnapshot: false`는 DOM, SVG처럼 픽셀이 필요 없는 대상을 움직이는 효과에 맞습니다. 그 단계는 캡처를 아예 건너뜁니다.

## 스냅샷 없는 코어 사용하기

두 단계 모두 `needsSnapshot: false`라면 `/core`를 가져오세요. 캡처 어댑터, 파티클 렌더러, 내장 오디오가 모듈 그래프에 들어오지 않습니다.

```ts
import Disintegrator, { defineEffect } from 'vanilla-disintegrate/core';

const fade = defineEffect({
  remove: {
    needsSnapshot: false,
    animate: ({ element, layer }) => {
      const visual = element.cloneNode(true) as HTMLElement;
      Object.assign(visual.style, {
        height: '100%',
        inset: '0',
        margin: '0',
        pointerEvents: 'none',
        position: 'absolute',
        width: '100%',
      });
      layer.append(visual);
      return visual.animate([{ opacity: 1 }, { opacity: 0 }], { duration: 240 });
    },
  },
  restore: {
    needsSnapshot: false,
    animate: ({ element, layer }) => {
      const visual = element.cloneNode(true) as HTMLElement;
      Object.assign(visual.style, {
        height: '100%',
        inset: '0',
        margin: '0',
        pointerEvents: 'none',
        position: 'absolute',
        width: '100%',
      });
      layer.append(visual);
      return visual.animate([{ opacity: 0 }, { opacity: 1 }], { duration: 240 });
    },
  },
});

const effects = new Disintegrator({ effect: fade });
```

## 애니메이션 컨텍스트

팩토리가 받는 값입니다.

- `operation` — `remove` 또는 `restore`
- `element` — 요소 자체
- `bounds` — 화면상의 위치, `DOMRectReadOnly`
- `layer` — 그 위치에 이미 놓인 빈 오버레이
- `snapshot` — 캡처된 캔버스 또는 `null`
- `visual` — 스냅샷을 그려 넣은 원본 크기 캔버스, 처음 쓸 때 만들어짐
- `signal` — 작업이 취소되거나 인스턴스가 파괴되면 발동
- `random()` — 이 작업용 난수, 시드가 있어 재현 가능
- `reducedMotion` — 팩토리가 실행되는 동안 항상 `false`; 동작 축소 요청은 호출 전에 작업을 건너뜀
- `addCleanup(fn)` — 여기 등록한 정리는 어떤 결과에도 실행됨

복원 시 `bounds`는 삭제 전 위치가 아닌 **삽입 후 새 위치**를 나타냅니다.

## 반환 값

애니메이션 팩토리는 다음 값을 반환할 수 있습니다.

```ts
type AnimationResult =
  | Animation
  | PromiseLike<unknown>
  | {
      element?: HTMLElement;
      finished: PromiseLike<unknown>;
      duration?: number;
      layoutDelay?: number;
      cancel?(): void;
      dispose?(): void;
    }
  | null;
```

Web Animation, Promise, Canvas나 WebGL 루프, 다른 엔진의 래퍼가 모두 이 계약에 맞습니다. `cancel()`은 재생을 멈추고 `dispose()`는 완료, 취소, 실패 여부와 관계없이 렌더러 자원을 해제합니다.

## 재사용 가능한 프리셋 만들기

사용자 `effect`는 기본적으로 무음입니다. 애니메이션과 오디오를 하나의 완성된 선택으로 함께 재사용하려면 완성 프리셋으로 묶으세요.

```ts
import { definePreset } from 'vanilla-disintegrate';

const vortex = definePreset({
  effect: particleVortex,
  sound: {
    remove: { src: 'vapor', volume: 0.35 },
    restore: { src: 'vapor', volume: 0.35, reverse: true },
  },
});

const effects = new Disintegrator({
  preset: 'vortex',
  presets: { vortex },
});

effects.remove(element);
```

내장 프리셋 이름은 루트 및 `/snapdom` 엔트리가 등록합니다. `/core`는 `presets`로 제공하거나 `preset`에 인라인으로 전달한 프리셋만 사용합니다.

## 사용자 사운드

사운드는 시각 단계와 분리하세요. 생성자는 독립된 `remove`와 `restore` 정의를 받으며 사용자 효과가 무음이어야 하면 `sound`를 생략합니다.

```ts
const effects = new Disintegrator({
  effect: particleVortex,
  sound: {
    remove: { src: '/sounds/remove.ogg', volume: 0.35 },
    restore: ({ signal }) => startMyAudioEngine(signal),
  },
});
```

`src`는 내장 이름, `URL`, 로컬 `Blob`/`File`, `ArrayBuffer`, typed-array view 또는 `AudioBuffer`도 받습니다. 오디오 오류는 `onError`로 전달되지만 애니메이션과 DOM 변경은 계속됩니다.
