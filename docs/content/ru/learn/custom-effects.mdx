Свой эффект — это две анимации: одна на удаление элемента, вторая на его восстановление. Анимацию и звук пишете вы. Библиотека снимает элемент, измеряет его и берёт на себя отмену и уборку.

## Настроить частицы через плейграунд

Плейграунд на главной создаёт готовый пользовательский эффект с отдельными настройками частиц и звука для удаления и восстановления. Например, такой код сочетает удаление `scatter` с восстановлением `vapor`:

```ts
import Disintegrator, { createParticleEffect, particlePresets } from 'vanilla-disintegrate/snapdom';

const sharedSoundOptions = {
  volume: 0.32,
  playbackRate: 1,
  delay: 0,
  fadeDuration: 0.18,
};

export const disintegrator = new Disintegrator({
  effect: createParticleEffect({
    remove: particlePresets.scatter,
    restore: particlePresets.vapor,
  }),
  sound: {
    remove: {
      ...sharedSoundOptions,
      src: 'scatter',
      reverse: false,
    },
    restore: {
      ...sharedSoundOptions,
      src: 'vapor',
      reverse: true,
    },
  },
});
```

`createParticleEffect()` использует встроенный рендерер частиц. Настройте обе фазы в плейграунде, скопируйте полученный код и используйте его без самостоятельной реализации рендерера на Canvas или WebGL. Следующий раздел нужен, только если вы хотите реализовать саму отрисовку.

Все параметры движения, их значения по умолчанию, допустимые диапазоны и низкоуровневые фабрики фаз описаны в [API частиц](/ru/docs/reference/particles/).

## Управлять качеством рендеринга частиц

`renderQuality` управляет разрешением встроенного WebGL-рендерера независимо от адаптера захвата. Режим `auto` по умолчанию ограничивает расход памяти и нагрузку на GPU: исходная текстура рендерера содержит не больше 2 000 000 пикселей и 2 048 пикселей по одной стороне, а расширенная поверхность анимации — не больше 4 000 000 пикселей.

Используйте `exact`, если сохранение полного разрешения снимка важнее этих программных лимитов:

```ts
const exactEffect = createParticleEffect({
  remove: { ...particlePresets.vapor, renderQuality: 'exact' },
  restore: { ...particlePresets.scatter, renderQuality: 'exact' },
});
```

Либо задайте собственный бюджет:

```ts
const boundedEffect = createParticleEffect({
  remove: {
    ...particlePresets.vapor,
    renderQuality: {
      maxSourcePixels: 4_000_000,
      maxSourceDimension: 4096,
      maxRenderPixels: 8_000_000,
    },
  },
});
```

`exact` отключает программное уменьшение, но не может обойти аппаратные ограничения WebGL на текстуру и viewport. Если устройство не поддерживает требуемую точную поверхность, ошибка попадёт в `onError` вместо скрытого ухудшения качества. Для неизвестных или больших элементов выбирайте `auto`: расход при полном разрешении растёт примерно пропорционально квадрату device pixel ratio.

## Изменить потолок контекстов WebGL

```ts
import { configureParticleContexts } from 'vanilla-disintegrate/snapdom';

configureParticleContexts({ maxContexts: 2, maxIdleContexts: 1 });
```

Рендерер частиц держит одновременно не больше 4 контекстов WebGL2 на всю страницу, из них до 2 остаются прогретыми для повторного использования после завершения эффекта. Этот потолок общий для страницы, а не для каждого эффекта отдельно: браузер и так ограничивает число живых контекстов на странице, а если бы два эффекта запрашивали разные значения, единственно верного ответа не нашлось бы.

Эффект, которому не хватило контекста из-за упора в потолок, проходит тот же путь, что и браузер без WebGL2: `remove()` всё равно открепляет элемент, `restore()` всё равно показывает его, операция завершается со статусом `skipped`, а в `onError` попадает общая ошибка «не создал анимацию» — без указания на то, что причина именно в нехватке контекстов. Вызовите `configureParticleContexts()` один раз, до первого запуска любого эффекта, чтобы изменить потолок на весь срок жизни страницы. Понижайте его на устройствах с ограниченной памятью; повышайте только до предела, который допускает сам браузер, — превышение лишь переносит место, где контексты будут отброшены.

## Эффект из снимка и частиц

Пример ниже берёт непрозрачные пиксели из `snapshot`, превращает их в Canvas-частицы и ведёт через вихрь. Эффект использует снимок, а `needsSnapshot: true` уже является значением по умолчанию, поэтому этот параметр можно не указывать.

Сохраните приведённый выше код в файле `particle-vortex.ts`, затем импортируйте `particleVortex` и передайте его в конструктор:

```ts
import Disintegrator from 'vanilla-disintegrate/snapdom';

import { particleVortex } from './particle-vortex';

const effects = new Disintegrator({ effect: particleVortex });

effects.remove(element, { retain: true });
effects.restore(insertedElement);
```

Демо выше и блок кода взяты из одного файла, так что работает ровно то, что вы видите.

`needsSnapshot: false` подходит эффекту, который анимирует DOM, SVG или что-то ещё, чему пиксели не нужны. Тогда для этой фазы захвата не будет вовсе.

## Лёгкий вход без снимков

Если обе фазы задают `needsSnapshot: false`, импортируйте `/core`: адаптер захвата, рендерер частиц и встроенное аудио не попадут в граф модулей.

```ts
import Disintegrator, { defineEffect } from 'vanilla-disintegrate/core';

const fade = defineEffect({
  remove: {
    needsSnapshot: false,
    animate: ({ element, layer }) => {
      const visual = element.cloneNode(true) as HTMLElement;
      Object.assign(visual.style, {
        height: '100%',
        inset: '0',
        margin: '0',
        pointerEvents: 'none',
        position: 'absolute',
        width: '100%',
      });
      layer.append(visual);
      return visual.animate([{ opacity: 1 }, { opacity: 0 }], { duration: 240 });
    },
  },
  restore: {
    needsSnapshot: false,
    animate: ({ element, layer }) => {
      const visual = element.cloneNode(true) as HTMLElement;
      Object.assign(visual.style, {
        height: '100%',
        inset: '0',
        margin: '0',
        pointerEvents: 'none',
        position: 'absolute',
        width: '100%',
      });
      layer.append(visual);
      return visual.animate([{ opacity: 0 }, { opacity: 1 }], { duration: 240 });
    },
  },
});

const effects = new Disintegrator({ effect: fade });
```

## Контекст анимации

Фабрика получает:

- `operation` — `remove` или `restore`
- `element` — сам элемент
- `bounds` — где он на экране, как `DOMRectReadOnly`
- `layer` — пустой оверлей, уже поставленный поверх этих границ
- `snapshot` — снятый канвас или `null`
- `visual` — канвас в полный размер с нарисованным снимком, создаётся при первом обращении
- `signal` — сработает при отмене операции или уничтожении экземпляра
- `random()` — случайные числа для этой операции, с сидом, чтобы прогон можно было повторить
- `reducedMotion` — всегда `false` внутри запущенной фабрики; запрос на уменьшение движения пропускает операцию до её вызова
- `addCleanup(fn)` — что сюда положите, выполнится при любом исходе

При восстановлении `bounds` — это **новое** место, куда вы вставили элемент, а не то, откуда его удалили.

## Допустимые результаты

Фабрика анимации может вернуть:

```ts
type AnimationResult =
  | Animation
  | PromiseLike<unknown>
  | {
      element?: HTMLElement;
      finished: PromiseLike<unknown>;
      duration?: number;
      layoutDelay?: number;
      cancel?(): void;
      dispose?(): void;
    }
  | null;
```

Так подойдёт и Web Animation, и промис, и цикл на Canvas или WebGL, и обёртка над чужим движком. `cancel()` останавливает проигрывание. `dispose()` освобождает то, что выделил ваш рендерер, и вызывается независимо от того, доиграла анимация, была отменена или упала.

## Создать свой пресет

Пользовательский `effect` по умолчанию бесшумный. Если анимация и аудио должны использоваться вместе как один готовый выбор, объедините их в полный пресет:

```ts
import { definePreset } from 'vanilla-disintegrate';

const vortex = definePreset({
  effect: particleVortex,
  sound: {
    remove: { src: 'vapor', volume: 0.35 },
    restore: { src: 'vapor', volume: 0.35, reverse: true },
  },
});

const effects = new Disintegrator({
  preset: 'vortex',
  presets: { vortex },
});

effects.remove(element);
```

Имена встроенных пресетов зарегистрированы в корневом входе и `/snapdom`. `/core` видит только пресеты, переданные через `presets` или инлайном через `preset`.

## Свой звук

Храните звук отдельно от визуальных фаз. Конструктор принимает независимые определения `remove` и `restore`; не передавайте `sound`, если пользовательский эффект должен быть бесшумным.

```ts
const effects = new Disintegrator({
  effect: particleVortex,
  sound: {
    remove: { src: '/sounds/remove.ogg', volume: 0.35 },
    restore: ({ signal }) => startMyAudioEngine(signal),
  },
});
```

`src` также принимает встроенное имя, `URL`, локальный `Blob`/`File`, `ArrayBuffer`, typed-array view или `AudioBuffer`. Если звук не сложился, ошибка уходит в `onError`, а анимация и изменение DOM продолжаются.
