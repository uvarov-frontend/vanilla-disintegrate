기본 export는 클래스 하나입니다. 캡처, 애니메이션, 사운드, 이웃 요소의 레이아웃 이동, 백그라운드 준비, 보관된 노드 저장소를 함께 묶습니다.

## 생성자

```ts
import Disintegrator from 'vanilla-disintegrate/snapdom';

const effects = new Disintegrator(options);
```

| 옵션                   | 타입                               | 기본값          | 하는 일                                                      |
| ---------------------- | ---------------------------------- | --------------- | ------------------------------------------------------------ |
| `effect`               | `EffectSelection`                  | `'dust'`        | 작업이 따로 고르지 않았을 때 쓰는 효과                       |
| `effects`              | `Record<string, EffectDefinition>` | `{}`            | 이름으로 고를 수 있는 사용자 효과                            |
| `sound`                | `boolean \| SoundDefinition`       | `false`         | `true`는 단계 사운드를 재생, 정의를 주면 대체                |
| `layout`               | `boolean \| LayoutOptions`         | `true`          | 삭제 후 이웃 요소를 새 자리로 이동                           |
| `preparation`          | `boolean \| PreparationOptions`    | `false`         | 백그라운드에서 스냅샷을 미리 캡처                            |
| `respectReducedMotion` | `boolean`                          | `true`          | 사용자가 동작 축소를 요청하면 애니메이션 생략                |
| `capture`              | `SnapshotCapture`                  | —               | 요소를 캔버스로 변환. `/snapdom` 진입점에는 SnapDOM이 연결됨 |
| `overlayRoot`          | `HTMLElement \| () => HTMLElement` | `document.body` | 애니메이션 오버레이를 붙일 위치                              |
| `zIndex`               | `number`                           | `2147483646`    | 그 오버레이의 쌓임 순서                                      |
| `random`               | `() => number`                     | `Math.random`   | 시드 소스, 작업마다 한 번 호출                               |
| `snapdom`              | `SnapdomOptions`                   | —               | SnapDOM의 `toCanvas()`로 전달. `/snapdom` 진입점 전용        |
| `onTrigger`            | `(context) => void`                | —               | 검증 후, 캡처 시작 전                                        |
| `onStart`              | `(context) => void`                | —               | DOM 변경 후 재생이 시작될 때                                 |
| `onComplete`           | `(context) => void`                | —               | 시각 단계가 정상 종료된 뒤                                   |
| `onError`              | `(error, context) => void`         | —               | 캡처, 애니메이션, 사운드, 콜백 오류                          |

## remove(target, options?)

요소를 측정하고 분리한 뒤 `EffectOperation`을 동기적으로 반환합니다.

```ts
const operation = effects.remove('.card', {
  effect: 'scatter',
  retain: true,
  sound: true,
  layout: { duration: 260 },
  detach: (element) => element.remove(),
});
```

`detach`는 기본 `element.remove()` 커밋을 대체합니다. 반응형 렌더러가 자체 상태로 노드를 제거해야 할 때 사용하세요. 콜백이 예외를 던지면 `onError`로 전달되고 네이티브 제거로 안전하게 폴백합니다.

`target`은 `HTMLElement` 또는 selector입니다. selector가 없으면 작업 시작 전에 오류를 던집니다.

## restore(target, options?)

연결되고 측정 가능한 요소를 현재 지오메트리에서 애니메이션합니다. 분리된 요소나 0 크기는 동기 오류입니다.

## 보관된 요소

```ts
const element = effects.take(removalId); // HTMLElement | null
const discarded = effects.discard(removalId); // boolean
const count = effects.discardAll(); // number
```

## 스냅샷 준비

```ts
const unregister = effects.register(elements);
await effects.prepare(elements);
effects.invalidate(elements);
effects.clearPrepared();
```

`register()`는 설정한 전략을 따릅니다. `prepare()`는 백그라운드 준비가 꺼져 있어도 즉시 캡처하며, 모든 요소가 끝나면 아무 값도 돌려주지 않습니다.

`random`에 고정값을 넘기면 효과를 재현할 수 있습니다. 같은 시드는 매 실행마다 파티클을 똑같이 배치하며, 시각 회귀 테스트가 가능한 이유가 바로 이것입니다.

## destroy()

실행 중인 작업과 observer를 중지하고 스냅샷 및 보관 노드를 해제합니다. 반복 호출은 안전하지만 파괴 후 새 작업은 허용되지 않습니다.

## EffectOperation

```ts
interface EffectOperation {
  readonly operation: 'remove' | 'restore';
  readonly removalId: RemovalId | null;
  readonly finished: Promise<{
    operation: 'remove' | 'restore';
    status: 'completed' | 'cancelled' | 'skipped';
    removalId: RemovalId | null;
  }>;
  cancel(): void;
}
```

작업 객체에는 의도적으로 `element` 속성이 없습니다. 개별 작업 옵션이 인스턴스 기본값보다 우선합니다.
