默认导出就是一个类。它把捕获、动画、声音、相邻元素的位移、后台准备以及保留节点的存储串在一起。

根入口和 `/snapdom` 会预先注册四种内置效果，并默认使用 `dust`；只有 `/snapdom` 还提供捕获适配器。`/core` 提供相同的生命周期 API，但不带默认效果、粒子和内置声音。`/particles` 提供工厂与效果定义，而不是 `Disintegrator` 类。

## 构造函数

```ts
import Disintegrator from 'vanilla-disintegrate/snapdom';

const effects = new Disintegrator(options);
```

| 选项                   | 类型                                                        | 默认值          | 作用                                             |
| ---------------------- | ----------------------------------------------------------- | --------------- | ------------------------------------------------ |
| `effect`               | `EffectSelection`                                           | `'dust'`¹       | 操作未指定时使用的效果                           |
| `effects`              | `Record<string, EffectDefinition>`                          | `{}`            | 自定义效果，之后可按名称选用                     |
| `sound`                | `boolean \| SoundDefinition`                                | `false`         | `true` 播放各阶段的声音；传定义则替换它们        |
| `layout`               | `boolean \| LayoutOptions`                                  | `true`          | 删除后把相邻元素移动到新位置                     |
| `preparation`          | `boolean \| PreparationOptions`                             | `visible-idle`  | 在后台准备已注册元素                             |
| `audioPreparation`     | `false \| 'immediate' \| 'idle' \| AudioPreparationOptions` | `'immediate'`   | 只准备已启用的声音；`sound: false` 时不执行工作  |
| `respectReducedMotion` | `boolean`                                                   | `true`          | 用户要求减少动效时跳过动画                       |
| `capture`              | `SnapshotCapture`                                           | SnapDOM¹        | 把元素变成画布                                   |
| `overlayRoot`          | `HTMLElement \| () => HTMLElement`                          | `document.body` | 动画覆盖层挂载到哪里                             |
| `zIndex`               | `number`                                                    | `2147483646`    | 该覆盖层的层级                                   |
| `random`               | `() => number`                                              | `Math.random`   | 种子来源，每次操作调用一次                       |
| `snapdom`              | `SnapdomOptions`                                            | —               | 传给 SnapDOM 的 `toCanvas()`，仅 `/snapdom` 入口 |
| `onTrigger`            | `(context) => void`                                         | —               | 校验之后、开始捕获之前                           |
| `onStart`              | `(context) => void`                                         | —               | DOM 变更之后，播放开始时                         |
| `onComplete`           | `(context) => void`                                         | —               | 视觉阶段正常结束后                               |
| `onError`              | `(error, context) => void`                                  | —               | 捕获、动画、声音与回调的错误                     |

¹ `dust` 与 SnapDOM 默认值一起适用于 `/snapdom`；根入口提供 `dust`，但不提供捕获。`/core` 两者都不提供。

操作失败时，`context.operation` 为 `remove` 或 `restore`。后台快照准备失败会报告 `prepare`，不会被误标为内容操作。

传入固定的 `random` 可让效果复现：相同种子每次都会生成相同粒子布局，适合视觉回归测试。

## remove(target, options?)

测量并分离元素，同步返回 `EffectOperation`。

```ts
const operation = effects.remove('.card', {
  effect: 'scatter',
  retain: true,
  sound: true,
  layout: { duration: 260 },
  detach: (element) => element.remove(),
});
```

`detach` 会替换默认的 `element.remove()` 提交，适合让响应式渲染器通过自身状态移除节点。若回调抛出错误，错误会传给 `onError`，库会回退到原生移除。

`target` 可为 `HTMLElement` 或选择器。找不到选择器时会在操作开始前抛出错误。

## restore(target, options?)

在当前几何位置动画显示已连接、可测量的元素。

```ts
const operation = effects.restore(element, {
  effect: 'scatter',
  sound: true,
});
```

分离节点或零尺寸会同步抛出错误。

## 节点存储

```ts
const element = effects.take(removalId); // HTMLElement | null
const discarded = effects.discard(removalId); // boolean
const count = effects.discardAll(); // number
```

`take()` 会消费存储中的条目。`discard()` 与 `discardAll()` 只释放引用，不会插入内容。

## 快照准备

```ts
const unregister = effects.register(elements);
await effects.prepare(elements);
effects.invalidate(elements);
effects.clearPrepared();
```

`register()` 遵循你配置的策略。`prepare()` 会立即捕获，即使后台准备是关闭的；全部元素完成后它不返回任何值。

同一元素的重复注册采用引用计数：每个注销函数只释放自己的注册，最后一个注册释放后才停止观察。

## 音频准备

```ts
await effects.prepareAudio(['dust', 'wind']);
effects.discardPreparedAudio('dust');
effects.clearPreparedAudio();
```

实例设置 `sound: true` 后会自动准备默认效果。声音关闭时显式方法仍可使用。解码缓冲区存放在有界 LRU 缓存中。

## destroy()

```ts
effects.destroy();
```

取消活动操作，停止观察器与后台任务，释放快照和解码音频的所有权，并清除保留节点。最后一个 `Disintegrator` 所有者销毁时，共享播放上下文才会关闭。重复调用 `destroy()` 是安全的；销毁后不能开始新操作。

## EffectOperation

```ts
interface EffectOperation {
  readonly operation: 'remove' | 'restore';
  readonly removalId: RemovalId | null;
  readonly finished: Promise<{
    operation: 'remove' | 'restore';
    status: 'completed' | 'cancelled' | 'skipped' | 'rejected';
    removalId: RemovalId | null;
  }>;
  cancel(): void;
}
```

操作对象不会暴露 `element`，并在结束后释放元素引用。

| 状态        | 内容操作                       | `finished` 完成时间 |
| ----------- | ------------------------------ | ------------------- |
| `completed` | 已提交；视觉阶段正常完成       | 视觉资源清理后      |
| `cancelled` | 已提交；视觉或音频播放已停止   | 取消清理后          |
| `skipped`   | 已提交，但没有可运行的视觉阶段 | 回退清理后          |
| `rejected`  | 未开始；DOM 未改变             | 当前所有者结束后    |

## 回调与优先级

实例回调会参与每次操作，也可以同时提供单次操作回调。单次操作选项覆盖实例默认值。保留节点记住的效果仅在 `restore()` 没有显式 `effect` 时使用。
