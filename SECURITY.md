# Security policy

## Supported versions

Security fixes are released for the latest published version of Vanilla Disintegrate.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/uvarov-frontend/vanilla-disintegrate/security/advisories/new). Do not include sensitive vulnerability details in a public issue.

Include the affected version, a minimal reproduction, the expected impact, and any known mitigations. You will receive acknowledgement after the report has been reviewed, followed by status updates while a fix is being prepared.
