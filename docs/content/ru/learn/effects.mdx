Каждое встроенное имя — это **пара**: одна анимация на удаление, вторая на возврат элемента. Анимация возврата написана отдельно, это не таймлайн удаления, проигранный назад.

## Четыре эффекта

| Имя       | Удаление                                                                                 | Восстановление                                          | Длительность |
| --------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------- | ------------ |
| `dust`    | Элемент рассыпается поднимающейся пылью.                                                 | Пыль собирается в конечной геометрии элемента.          | 900 ms       |
| `scatter` | Мелкие фрагменты растворяются слева направо и разлетаются с уклоном вверх.               | Фрагменты собираются из той же рассеянной области.      | 1170 ms      |
| `vapor`   | Поверхность отрывается вразнобой, верх уходит первым, и по пути вверх частицы разбухают. | Сужающийся поток пара конденсируется в видимый элемент. | 1030 ms      |
| `wind`    | Поток уносит частицы в сторону.                                                          | Тот же поток возвращает их со своего направления.       | 2040 ms      |

Обе фазы эффекта идут одинаковое время. `remove()` использует его как таймлайн удаления, `restore()` — как появление, и встроенный звук обрезается по нему.

```ts
effects.remove(card, { effect: 'dust' });
effects.restore(card, { effect: 'dust' });

effects.remove(card, { effect: 'scatter' });
effects.restore(card, { effect: 'scatter' });

effects.remove(card, { effect: 'vapor' });
effects.restore(card, { effect: 'vapor' });

effects.remove(card, { effect: 'wind' });
effects.restore(card, { effect: 'wind' });
```

## Эффект по умолчанию

```ts
const effects = new Disintegrator({ effect: 'vapor' });

effects.remove(firstElement); // vapor
effects.remove(secondElement, { effect: 'scatter' });
effects.restore(insertedElement, { effect: 'wind' });
```

## Запомненная пара

```ts
const removal = effects.remove(card, {
  effect: 'wind',
  retain: true,
});

await removal.finished;
const retained = effects.take(removal.removalId!);

if (retained) {
  list.prepend(retained);
  await effects.restore(retained).finished; // восстановление wind
}
```

Передайте `effect` в `restore()`, только если хотите сознательно заменить запомненную пару.

## Слоты звука

У каждой фазы собственный слот аудио. У `dust`, `scatter`, `vapor` и `wind` звук есть на обеих фазах: дорожка восстановления — та же запись, разворачиваемая при проигрывании через опцию `reverse`; фазы анимации при этом остаются самостоятельными. Звук подключается явно: `sound: true` включает встроенные дорожки для экземпляра или отдельного вызова, `sound: false` оставляет их выключенными, не меняя анимацию.
