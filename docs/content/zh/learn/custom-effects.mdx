自定义效果就是两段动画：一段用于删除元素，一段用于把它放回来。动画和声音由你来写。库负责捕获元素、测量位置，并处理取消和清理。

## 使用快照构建粒子效果

下面的示例从 `snapshot` 读取不透明像素，把它们变成 Canvas 粒子，再让粒子穿过漩涡。它需要这些像素，而快照本来就是默认拍的，所以里面没有 `needsSnapshot`。

<ParticleVortexSource />

将上面的源代码复制到项目中的 `particle-vortex.ts`，再使用与演示完全相同的效果：

```ts
import Disintegrator from 'vanilla-disintegrate/snapdom';

import { particleVortex } from './particle-vortex';

const effects = new Disintegrator({ effect: particleVortex });

effects.remove(element, { retain: true });
effects.restore(insertedElement);
```

上面的演示和代码块来自同一个文件，你看到运行的就是你拿到的。

`needsSnapshot: false` 适合动画 DOM、SVG 或其他不需要像素的效果。该阶段将完全跳过捕获。

## 使用无快照核心入口

若两个阶段都设置 `needsSnapshot: false`，请导入 `/core`：捕获适配器、粒子渲染器与内置音频都不会进入模块图。

```ts
import Disintegrator, { defineEffect } from 'vanilla-disintegrate/core';

const fade = defineEffect({
  remove: {
    needsSnapshot: false,
    animate: ({ element, layer }) => {
      const visual = element.cloneNode(true) as HTMLElement;
      Object.assign(visual.style, {
        height: '100%',
        inset: '0',
        margin: '0',
        pointerEvents: 'none',
        position: 'absolute',
        width: '100%',
      });
      layer.append(visual);
      return visual.animate([{ opacity: 1 }, { opacity: 0 }], { duration: 240 });
    },
  },
  restore: {
    needsSnapshot: false,
    animate: ({ element, layer }) => {
      const visual = element.cloneNode(true) as HTMLElement;
      Object.assign(visual.style, {
        height: '100%',
        inset: '0',
        margin: '0',
        pointerEvents: 'none',
        position: 'absolute',
        width: '100%',
      });
      layer.append(visual);
      return visual.animate([{ opacity: 0 }, { opacity: 1 }], { duration: 240 });
    },
  },
});

const effects = new Disintegrator({ effect: fade });
```

## 动画上下文

工厂会收到：

- `operation` — `remove` 或 `restore`
- `element` — 元素本身
- `bounds` — 它在屏幕上的位置，`DOMRectReadOnly`
- `layer` — 一个空的覆盖层，已经摆在这个位置上
- `snapshot` — 捕获到的画布，或 `null`
- `visual` — 画好快照的全尺寸画布，首次访问时才创建
- `signal` — 操作被取消或实例被销毁时触发
- `random()` — 本次操作的随机数，带种子，便于复现
- `reducedMotion` — 工厂运行时始终为 `false`；减少动效请求会在调用工厂前跳过操作
- `addCleanup(fn)` — 放进去的清理逻辑，无论结果如何都会执行

恢复时，`bounds` 描述的是**插入后的新位置**，而不是删除前的位置。

## 返回值

动画工厂可以返回：

```ts
type AnimationResult =
  | Animation
  | PromiseLike<unknown>
  | {
      element?: HTMLElement;
      finished: PromiseLike<unknown>;
      duration?: number;
      layoutDelay?: number;
      cancel?(): void;
      dispose?(): void;
    }
  | null;
```

因此 Web Animation、Promise、Canvas 或 WebGL 循环以及第三方引擎包装器都适用。`cancel()` 停止播放；`dispose()` 无条件释放渲染器资源，无论动画完成、取消还是失败都会执行。

## 创建可复用预设

自定义 `effect` 默认静音。若动画与音频应作为一个完整选项一起复用，请把它们包装成完整预设：

```ts
import { definePreset } from 'vanilla-disintegrate';

const vortex = definePreset({
  effect: particleVortex,
  sound: {
    remove: { src: 'vapor', volume: 0.35 },
    restore: { src: 'vapor', volume: 0.35, reverse: true },
  },
});

const effects = new Disintegrator({
  preset: 'vortex',
  presets: { vortex },
});

effects.remove(element);
```

内置预设名称由根入口与 `/snapdom` 注册。`/core` 只能看到通过 `presets` 提供或通过 `preset` 内联传入的预设。

## 自定义声音

视觉阶段与声音应保持分离。构造器接收独立的 `remove` 和 `restore` 定义；若自定义效果应保持静音，请省略 `sound`。

```ts
const effects = new Disintegrator({
  effect: particleVortex,
  sound: {
    remove: { src: '/sounds/remove.ogg', volume: 0.35 },
    restore: ({ signal }) => startMyAudioEngine(signal),
  },
});
```

`src` 还支持内置名称、`URL`、本地 `Blob`/`File`、`ArrayBuffer`、typed-array view 或 `AudioBuffer`。音频错误会传给 `onError`，但动画与 DOM 变更会继续执行。
