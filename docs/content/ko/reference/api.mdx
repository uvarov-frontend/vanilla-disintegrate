기본 export는 클래스 하나입니다. 캡처, 애니메이션, 사운드, 이웃 요소의 레이아웃 이동, 백그라운드 준비, 보관된 노드 저장소를 함께 묶습니다.

기본 진입점과 `/snapdom`은 네 가지 내장 효과를 미리 등록하고 `dust`를 기본값으로 사용합니다. 캡처 어댑터까지 제공하는 진입점은 `/snapdom`뿐입니다. `/core`는 같은 생명주기 API를 제공하지만 기본 효과, 파티클, 내장 사운드는 포함하지 않습니다. `/particles`는 팩토리와 효과 정의를 제공하며 `Disintegrator` 클래스는 제공하지 않습니다.

## 생성자

```ts
import Disintegrator from 'vanilla-disintegrate/snapdom';

const effects = new Disintegrator(options);
```

| 옵션                   | 타입                                                        | 기본값          | 하는 일                                                 |
| ---------------------- | ----------------------------------------------------------- | --------------- | ------------------------------------------------------- |
| `effect`               | `EffectSelection`                                           | `'dust'`¹       | 작업이 따로 고르지 않았을 때 쓰는 효과                  |
| `effects`              | `Record<string, EffectDefinition>`                          | `{}`            | 이름으로 고를 수 있는 사용자 효과                       |
| `sound`                | `boolean \| SoundDefinition`                                | `false`         | `true`는 단계 사운드를 재생, 정의를 주면 대체           |
| `layout`               | `boolean \| LayoutOptions`                                  | `true`          | 삭제 후 이웃 요소를 새 자리로 이동                      |
| `preparation`          | `boolean \| PreparationOptions`                             | `visible-idle`  | 등록된 요소를 백그라운드에서 준비                       |
| `audioPreparation`     | `false \| 'immediate' \| 'idle' \| AudioPreparationOptions` | `'immediate'`   | 켜진 사운드만 준비하며 `sound: false`이면 작업하지 않음 |
| `respectReducedMotion` | `boolean`                                                   | `true`          | 사용자가 동작 축소를 요청하면 애니메이션 생략           |
| `capture`              | `SnapshotCapture`                                           | SnapDOM¹        | 요소를 Canvas로 변환                                    |
| `overlayRoot`          | `HTMLElement \| () => HTMLElement`                          | `document.body` | 애니메이션 오버레이를 붙일 위치                         |
| `zIndex`               | `number`                                                    | `2147483646`    | 그 오버레이의 쌓임 순서                                 |
| `random`               | `() => number`                                              | `Math.random`   | 시드 소스, 작업마다 한 번 호출                          |
| `snapdom`              | `SnapdomOptions`                                            | —               | SnapDOM의 `toCanvas()`로 전달. `/snapdom` 진입점 전용   |
| `onTrigger`            | `(context) => void`                                         | —               | 검증 후, 캡처 시작 전                                   |
| `onStart`              | `(context) => void`                                         | —               | DOM 변경 후 재생이 시작될 때                            |
| `onComplete`           | `(context) => void`                                         | —               | 시각 단계가 정상 종료된 뒤                              |
| `onError`              | `(error, context) => void`                                  | —               | 캡처, 애니메이션, 사운드, 콜백 오류                     |

¹ `dust`와 SnapDOM 기본값은 `/snapdom`에 함께 적용됩니다. 기본 진입점은 `dust`만 제공하고, `/core`는 둘 다 제공하지 않습니다.

작업 오류의 `context.operation`은 `remove` 또는 `restore`입니다. 백그라운드 스냅샷 준비 오류는 `prepare`로 보고되어 콘텐츠 작업으로 잘못 표시되지 않습니다.

고정된 `random`을 전달하면 같은 시드가 매번 같은 파티클 배치를 만들어 시각 회귀 테스트에 활용할 수 있습니다.

## remove(target, options?)

요소를 측정하고 분리한 뒤 `EffectOperation`을 동기적으로 반환합니다.

```ts
const operation = effects.remove('.card', {
  effect: 'scatter',
  retain: true,
  sound: true,
  layout: { duration: 260 },
  detach: (element) => element.remove(),
});
```

`detach`는 기본 `element.remove()` 커밋을 대체합니다. 반응형 렌더러가 자체 상태로 노드를 제거해야 할 때 사용하세요. 콜백이 예외를 던지면 `onError`로 전달되고 네이티브 제거로 안전하게 폴백합니다.

`target`은 `HTMLElement` 또는 selector입니다. selector가 없으면 작업 시작 전에 오류를 던집니다.

## restore(target, options?)

연결되고 측정 가능한 요소를 현재 지오메트리에서 애니메이션합니다.

```ts
const operation = effects.restore(element, {
  effect: 'scatter',
  sound: true,
});
```

분리된 요소나 0 크기는 동기 오류입니다.

## 보관된 요소

```ts
const element = effects.take(removalId); // HTMLElement | null
const discarded = effects.discard(removalId); // boolean
const count = effects.discardAll(); // number
```

`take()`는 저장된 항목을 소비합니다. `discard()`와 `discardAll()`은 콘텐츠를 삽입하지 않고 참조만 해제합니다.

## 스냅샷 준비

```ts
const unregister = effects.register(elements);
await effects.prepare(elements);
effects.invalidate(elements);
effects.clearPrepared();
```

`register()`는 설정한 전략을 따릅니다. `prepare()`는 백그라운드 준비가 꺼져 있어도 즉시 캡처하며, 모든 요소가 끝나면 아무 값도 돌려주지 않습니다.

같은 요소를 여러 번 등록하면 참조 횟수를 셉니다. 각 해제 함수는 자신의 등록만 해제하며 마지막 등록이 해제된 뒤에만 관찰을 멈춥니다.

## 오디오 준비

```ts
await effects.prepareAudio(['dust', 'wind']);
effects.discardPreparedAudio('dust');
effects.clearPreparedAudio();
```

인스턴스에 `sound: true`를 설정하면 기본 효과가 자동으로 준비됩니다. 명시적 메서드는 사운드가 꺼져 있어도 동작합니다. 디코딩 버퍼는 제한된 LRU 캐시에 저장됩니다.

## destroy()

```ts
effects.destroy();
```

실행 중인 작업, observer, 백그라운드 작업을 중지하고 스냅샷과 디코딩 오디오 소유권 및 보관 노드를 해제합니다. 마지막 `Disintegrator` 소유자가 파괴될 때 공유 재생 컨텍스트가 닫힙니다. `destroy()`를 반복 호출해도 안전하지만 파괴 후 새 작업은 허용되지 않습니다.

## EffectOperation

```ts
interface EffectOperation {
  readonly operation: 'remove' | 'restore';
  readonly removalId: RemovalId | null;
  readonly finished: Promise<{
    operation: 'remove' | 'restore';
    status: 'completed' | 'cancelled' | 'skipped' | 'rejected';
    removalId: RemovalId | null;
  }>;
  cancel(): void;
}
```

작업 객체에는 의도적으로 `element` 속성이 없으며 완료되면 요소 참조를 해제합니다.

| 상태        | 콘텐츠 작업                          | `finished` 완료 시점  |
| ----------- | ------------------------------------ | --------------------- |
| `completed` | 반영됨; 시각 단계가 정상 완료됨      | 시각 리소스 정리 후   |
| `cancelled` | 반영됨; 시각 또는 오디오가 중단됨    | 취소 정리 후          |
| `skipped`   | 반영됨; 실행 가능한 시각 단계가 없음 | 폴백 정리 후          |
| `rejected`  | 시작되지 않음; DOM 변경 없음         | 현재 소유자가 끝난 후 |

## 콜백과 우선순위

인스턴스 콜백은 모든 작업에 실행되며 개별 작업 콜백도 함께 지정할 수 있습니다. 개별 작업 옵션이 인스턴스 기본값을 덮어씁니다. 보관된 노드가 기억한 효과는 `restore()`에 명시적인 `effect`가 없을 때만 사용됩니다.
