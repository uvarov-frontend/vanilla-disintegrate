Each built-in name is a **pair**: one animation for removing, one for putting the element back. The restore animation is written separately — it is not a removal timeline played in reverse.

## The four effects

| Name      | Remove                                                                          | Restore                                                      | Length  |
| --------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------ | ------- |
| `dust`    | The element breaks into rising dust.                                            | Dust collects into the element's final geometry.             | 900 ms  |
| `scatter` | Fine fragments dissolve left to right and drift with an upward bias.            | Fragments gather from the same scattered field.              | 1170 ms |
| `vapor`   | The surface lifts away at random, the top going first, and swells as it climbs. | A narrowing vapor stream condenses into the visible element. | 1030 ms |
| `wind`    | A stream carries particles sideways.                                            | The same stream returns them from its direction.             | 2040 ms |

Both phases of an effect run for the same length. `remove()` uses it as the removal timeline, `restore()` as the entrance one, and a bundled sound is trimmed to it.

```ts
effects.remove(card, { effect: 'dust' });
effects.restore(card, { effect: 'dust' });

effects.remove(card, { effect: 'scatter' });
effects.restore(card, { effect: 'scatter' });

effects.remove(card, { effect: 'vapor' });
effects.restore(card, { effect: 'vapor' });

effects.remove(card, { effect: 'wind' });
effects.restore(card, { effect: 'wind' });
```

## Select a default

Set a default on the instance and override it only for individual operations.

```ts
const effects = new Disintegrator({
  effect: 'vapor',
});

effects.remove(firstElement); // vapor
effects.remove(secondElement, { effect: 'scatter' });
effects.restore(insertedElement, { effect: 'wind' });
```

## Restore with the remembered pair

When a retained node is taken and inserted again, `restore()` can recover the effect chosen during removal.

```ts
const removal = effects.remove(card, {
  effect: 'wind',
  retain: true,
});

await removal.finished;

const retained = effects.take(removal.removalId!);
if (retained) {
  list.prepend(retained);
  await effects.restore(retained).finished; // wind restore
}
```

Pass `effect` to `restore()` when a different pair is intentional.

## Sound slots

Every phase has its own sound slot, so eight in total.

`dust`, `scatter`, `vapor` and `wind` have audio on both phases. Their restore sound is the removal file played backwards through the `reverse` option; the animation phases remain independent.

Sound is off unless you ask for it. `sound: true` turns on the built-in audio for an instance or for one call, `sound: false` turns it off without changing the animation.
