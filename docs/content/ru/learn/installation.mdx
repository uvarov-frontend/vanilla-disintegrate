Vanilla Disintegrate воссоздаёт узнаваемый эффект **«щелчка Таноса»** при удалении и возврате любого измеримого DOM-элемента.

## Установка

Используйте любой поддерживаемый пакетный менеджер:

```bash
# npm
npm install vanilla-disintegrate @zumer/snapdom

# Yarn
yarn add vanilla-disintegrate @zumer/snapdom

# pnpm
pnpm add vanilla-disintegrate @zumer/snapdom

# Bun
bun add vanilla-disintegrate @zumer/snapdom
```

Библиотека снимает внешний вид элемента до распада на частицы, а движок захвата выбираете вы. Пакет содержит пять tree-shakable точек входа:

| Точка входа                      | Состав                                                                                               | Требует          |
| -------------------------------- | ---------------------------------------------------------------------------------------------------- | ---------------- |
| `vanilla-disintegrate/core`      | Жизненный цикл, layout и аудио для своих эффектов, без частиц и готовых пресетов.                    | Ничего           |
| `vanilla-disintegrate/particles` | Фабрики частиц и переиспользуемые настройки геометрии.                                               | Ничего           |
| `vanilla-disintegrate/sounds`    | URL четырёх встроенных аудиофайлов без runtime библиотеки.                                           | Ничего           |
| `vanilla-disintegrate`           | `Disintegrator` с четырьмя полными визуально-звуковыми пресетами. `capture` передаёте вы.            | Ничего           |
| `vanilla-disintegrate/snapdom`   | Те же полные пресеты с [SnapDOM](https://zumerlab.github.io/snapdom/) в роли `capture` по умолчанию. | `@zumer/snapdom` |

Корневой вход и `/snapdom` экспортируют одинаковый API `Disintegrator`. Каждый экземпляр обязан получить ровно один полный `preset` или один пользовательский `effect`; неявного значения по умолчанию нет.

`/core` экспортирует `Disintegrator`, `defineEffect`, `definePreset` и публичные типы. `/particles` экспортирует `createParticleEffect`, `particlePresets`, обе фабрики анимации частиц и их типы, но не создаёт экземпляр. Так можно вручную собрать только нужные слои. В примере встроенная геометрия используется как бесшумный пользовательский эффект, а `captureElement` обозначает адаптер из следующего раздела:

```ts
import Disintegrator from 'vanilla-disintegrate/core';
import { createParticleEffect, particlePresets } from 'vanilla-disintegrate/particles';

const effects = new Disintegrator({
  capture: captureElement,
  effect: createParticleEffect({ remove: particlePresets.dust }),
});
```

Для самого короткого подключения импортируйте `/snapdom` и выберите один полный пресет:

```ts
import Disintegrator from 'vanilla-disintegrate/snapdom';

const effects = new Disintegrator({ preset: 'dust' });
const card = document.querySelector<HTMLElement>('.card');

if (card) {
  effects.remove(card);
}
```

`remove()` сразу возвращает объект операции. Ожидайте `operation.finished`, только если следующему действию нужно дождаться конца визуального эффекта.

## Удаление с возможностью вернуть узел

Задавайте `retain: true`, только если исходный узел может понадобиться снова. Место повторной вставки по-прежнему выбирает приложение.

```ts
const removal = effects.remove(card, {
  retain: true,
});

await removal.finished;

if (removal.removalId) {
  const retained = effects.take(removal.removalId);

  if (retained) {
    list.append(retained);
    await effects.restore(retained).finished;
  }
}
```

Если в `restore()` не передан другой `preset` или пользовательский `effect`, библиотека использует полную конфигурацию, запомненную при удалении.

## Другой движок захвата

`capture` — функция: принимает элемент, возвращает `<canvas>` или промис с ним. Подойдёт любая библиотека, которая это умеет, например `html2canvas`:

```ts
import html2canvas from 'html2canvas';
import Disintegrator from 'vanilla-disintegrate';

const effects = new Disintegrator({
  preset: 'dust',
  capture: (element, context) => {
    if (context.signal.aborted) throw new DOMException('Capture aborted.', 'AbortError');

    return html2canvas(element, {
      backgroundColor: null,
      logging: false,
      scale: 1,
      useCORS: true,
      onclone: (_document, clone) => {
        if (context.restoreRootOpacity !== undefined) {
          clone.style.setProperty('opacity', context.restoreRootOpacity, 'important');
        }
      },
    });
  },
});
```

Переданная функция полностью заменяет захват. На этом пути импортируйте корневой вход `vanilla-disintegrate`: у него нет обязательных runtime-зависимостей. `@zumer/snapdom` — необязательная peer-зависимость, которая нужна только входу `/snapdom`, поэтому здесь SnapDOM не попадёт в граф модулей.

## Подключение локально или через CDN

Если нужно быстро интегрировать Vanilla Disintegrate без сборщика или пакетного менеджера, подключите библиотеку через CDN либо [скачайте архив](https://cdn.jsdelivr.net/npm/vanilla-disintegrate@latest/vanilla-disintegrate-iife.zip) с актуальной версией для локального использования.

IIFE-сборка уже содержит SnapDOM и создаёт глобальный объект `VanillaDisintegrate`:

```html
<script src="https://cdn.jsdelivr.net/npm/vanilla-disintegrate@latest/dist/vanilla-disintegrate.iife.min.js"></script>
<script>
  const effects = new VanillaDisintegrate.Disintegrator({ preset: 'dust' });
  effects.remove(document.querySelector('.card'));
</script>
```

В архиве уже находятся минимальный `index.html`, IIFE-сборка, лицензии и все встроенные звуки. Запускайте распакованный каталог через локальный HTTP-сервер, чтобы браузер мог загрузить аудио. Если копируете IIFE вручную, оставьте каталог `sounds` рядом со скриптом; CDN-версия найдёт соответствующие ресурсы автоматически.

## Очистка

Когда владеющий экран окончательно уничтожен, вызовите `effects.destroy()`. Метод остановит операции, фоновые задачи и observers, освободит снимки и все сохранённые DOM-ссылки.

```ts
effects.destroy();
```

## Поддержка браузеров

Рантайм выпускается в формате ES2020 и использует Canvas, Web Animations (`Animation.finished` и `Element.getAnimations()`), `AbortController` и `requestAnimationFrame`. Встроенные пресеты используют штатный рендерер частиц на **WebGL2**, а кастомные эффекты могут работать на любом подходящем движке. Совокупная минимальная планка: <strong>Chrome 84+</strong>, <strong>Firefox 75+</strong>, <strong>Edge 84+</strong>, <strong>Opera 70+</strong> и <strong>Safari 15+</strong>. Та же планка действует для <strong>Chrome for Android 84+</strong> и <strong>iOS Safari 15+</strong>. Полифиллы не включены.

Там, где WebGL2 нет или контекст создать не удалось, визуалы встроенных пресетов деградируют, а не падают: `remove()` всё равно открепляет элемент, `restore()` всё равно показывает его, операция завершается со статусом `skipped`, а причина уходит в `onError`. Кастомные эффекты на WAAPI, CSS или Canvas 2D продолжают анимироваться и на старых движках.

Это минимальные версии по набору API, а не гарантия того, что любой GPU, драйвер или настройка браузера позволит создать контекст WebGL2.

Каждый одновременно запущенный визуал встроенного пресета арендует один контекст WebGL2. После завершения операции её текстуры удаляются, а контекст возвращается в привязанный к документу пул. Пул хранит не более двух простаивающих контекстов до 30 секунд, лишние уничтожает сразу и полностью освобождается при `pagehide`.

Создавайте `Disintegrator` только в браузере, а не во время серверного рендеринга. Внешние изображения, шрифты и стили должны разрешать CORS или проходить через proxy-опцию движка захвата, иначе они могут не попасть в снимок Canvas.
