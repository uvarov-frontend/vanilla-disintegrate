每个内置名称都是一**对**：一段用于删除，一段用于把元素放回去。恢复动画是单独写的，不是把删除时间线倒着播一遍。

## 四种效果

| 名称      | 删除                                             | 恢复                         | 时长    |
| --------- | ------------------------------------------------ | ---------------------------- | ------- |
| `dust`    | 元素化为向上飘散的尘埃。                         | 尘埃在元素最终几何位置聚合。 | 900 ms  |
| `scatter` | 细小碎片从左到右消散，并以向上为主扩散。         | 碎片从同一散布区域聚合。     | 1170 ms |
| `vapor`   | 表面无序地脱落，顶部先走，上升途中粒子逐渐胀大。 | 收束的蒸汽流凝结为可见元素。 | 1030 ms |
| `wind`    | 气流把粒子带向一侧。                             | 同一方向的气流把粒子送回。   | 2040 ms |

效果的两个阶段时长相同。`remove()` 用它作为删除时间线，`restore()` 用作入场时间线，内置声音也按它裁剪。

```ts
effects.remove(card, { effect: 'dust' });
effects.restore(card, { effect: 'dust' });

effects.remove(card, { effect: 'scatter' });
effects.restore(card, { effect: 'scatter' });

effects.remove(card, { effect: 'vapor' });
effects.restore(card, { effect: 'vapor' });

effects.remove(card, { effect: 'wind' });
effects.restore(card, { effect: 'wind' });
```

## 默认效果

```ts
const effects = new Disintegrator({
  effect: 'vapor',
});

effects.remove(firstElement); // vapor
effects.remove(secondElement, { effect: 'scatter' });
effects.restore(insertedElement, { effect: 'wind' });
```

## 使用记住的效果对

```ts
const removal = effects.remove(card, {
  effect: 'wind',
  retain: true,
});

await removal.finished;

const retained = effects.take(removal.removalId!);
if (retained) {
  list.prepend(retained);
  await effects.restore(retained).finished; // wind 恢复
}
```

只有明确需要不同动画时，才在 `restore()` 中覆盖 `effect`。

## 声音槽位

每个阶段都有独立声音槽。`dust`、`scatter`、`vapor` 与 `wind` 的两个阶段都有音频：恢复音轨即删除音轨在播放时经 `reverse` 选项倒放；动画的两个阶段仍然独立。声音需显式开启：`sound: true` 为实例或单次调用启用内置音频，`sound: false` 保持关闭且不改变动画。
