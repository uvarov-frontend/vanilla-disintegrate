Vanilla Disintegrate позволяет удалить любой измеримый DOM-элемент с эффектом **щелчка Таноса**. Точка входа `vanilla-disintegrate/snapdom` уже подключает захват через SnapDOM, а импорт CSS не нужен.

## Установка

Используйте любой поддерживаемый пакетный менеджер:

```bash
# npm
npm install vanilla-disintegrate @zumer/snapdom

# Yarn
yarn add vanilla-disintegrate @zumer/snapdom

# pnpm
pnpm add vanilla-disintegrate @zumer/snapdom

# Bun
bun add vanilla-disintegrate @zumer/snapdom
```

Библиотека снимает внешний вид элемента до распада на частицы, и движок захвата выбираете вы. Пакет содержит четыре tree-shakable точки входа:

| Точка входа                      | Состав                                                                                             | Требует          |
| -------------------------------- | -------------------------------------------------------------------------------------------------- | ---------------- |
| `vanilla-disintegrate/core`      | Жизненный цикл, layout и аудио для своих эффектов, без рендерера частиц и встроенных звуков.       | Ничего           |
| `vanilla-disintegrate/particles` | Фабрики частиц и определения четырёх встроенных эффектов.                                          | Ничего           |
| `vanilla-disintegrate`           | `Disintegrator` с четырьмя настроенными встроенными эффектами. `capture` передаёте вы.             | Ничего           |
| `vanilla-disintegrate/snapdom`   | Встроенные эффекты с [SnapDOM](https://zumerlab.github.io/snapdom/) в роли `capture` по умолчанию. | `@zumer/snapdom` |

Корневой вход и `/snapdom` экспортируют одинаковый API `Disintegrator`. `@zumer/snapdom` — необязательная peer-зависимость: она нужна только входу `/snapdom`, остальные входы к ней не обращаются.

`/core` экспортирует `Disintegrator`, `defineEffect` и публичные типы. Эффекта по умолчанию там намеренно нет: передайте объект эффекта или зарегистрированное имя. `/particles` экспортирует `builtInEffects`, обе фабрики анимации частиц и их типы, но не создаёт экземпляр. Так можно вручную собрать только нужные слои; `captureElement` ниже обозначает адаптер из следующего раздела:

```ts
import Disintegrator from 'vanilla-disintegrate/core';
import { builtInEffects } from 'vanilla-disintegrate/particles';

const effects = new Disintegrator({
  capture: captureElement,
  effect: 'dust',
  effects: builtInEffects,
});
```

Для своего эффекта без снимка вообще не импортируйте `/particles` и не передавайте `capture`: достаточно установить `needsSnapshot: false` в обеих фазах.

```ts
import Disintegrator from 'vanilla-disintegrate/snapdom';

const effects = new Disintegrator();
const card = document.querySelector<HTMLElement>('.card');

if (card) {
  effects.remove(card, { effect: 'dust' });
}
```

`remove()` сразу возвращает объект операции. Ожидайте `operation.finished`, только если следующему действию нужно дождаться конца визуального эффекта.

## Удаление с возможностью вернуть узел

Задавайте `retain: true`, только если исходный узел может понадобиться снова. Место повторной вставки по-прежнему выбирает приложение.

```ts
const removal = effects.remove(card, {
  effect: 'dust',
  retain: true,
});

await removal.finished;

if (removal.removalId) {
  const retained = effects.take(removal.removalId);

  if (retained) {
    list.append(retained);
    await effects.restore(retained).finished;
  }
}
```

Если в `restore()` не передан другой `effect`, библиотека использует пару, запомненную при удалении.

## Другой движок захвата

`capture` — функция: принимает элемент, возвращает `<canvas>` или промис с ним. Подойдёт любая библиотека, которая это умеет, например `html2canvas`:

```ts
import html2canvas from 'html2canvas';
import Disintegrator from 'vanilla-disintegrate';

const effects = new Disintegrator({
  capture: (element, context) => {
    if (context.signal.aborted) throw new DOMException('Capture aborted.', 'AbortError');

    return html2canvas(element, {
      backgroundColor: null,
      logging: false,
      scale: 1,
      useCORS: true,
      onclone: (_document, clone) => {
        if (context.restoreRootOpacity !== undefined) {
          clone.style.setProperty('opacity', context.restoreRootOpacity, 'important');
        }
      },
    });
  },
});
```

Переданная функция полностью заменяет захват. На этом пути импортируйте корневой вход `vanilla-disintegrate`: у него нет обязательных runtime-зависимостей, а SnapDOM не попадает в граф модулей.

## Подключение через script

IIFE-сборка уже содержит SnapDOM и создаёт глобальный объект `VanillaDisintegrate`:

```html
<script src="/vendor/vanilla-disintegrate.iife.min.js"></script>
<script>
  const effects = new VanillaDisintegrate.Disintegrator();
  effects.remove(document.querySelector('.card'));
</script>
```

Для встроенного аудио скопируйте каталог `dist/sounds` рядом со скриптом как `/vendor/sounds`: URL звуков вычисляются относительно IIFE-файла.

## Очистка

Когда владеющий экран окончательно уничтожен, вызовите `effects.destroy()`. Метод остановит операции, фоновые задачи и observers, освободит снимки и все сохранённые DOM-ссылки.

```ts
effects.destroy();
```

## Поддержка браузеров

Ядру нужны сборка ES2020, Canvas, Web Animations, `AbortController` и `requestAnimationFrame`. Четыре встроенных эффекта рисуют частицы через **WebGL2** — это и задаёт базовую планку: Chrome 80+, Firefox 74+, Edge 80+, Opera 67+ и Safari 15+.

Там, где WebGL2 нет или контекст создать не удалось, встроенные эффекты деградируют, а не падают: `remove()` всё равно открепляет элемент, `restore()` всё равно показывает его, операция завершается со статусом `skipped`, а причина уходит в `onError`. Кастомные эффекты на WAAPI, CSS или Canvas 2D продолжают анимироваться и на старых движках.

Каждый запущенный встроенный эффект держит один контекст WebGL2 и освобождает его сразу по завершении операции, поэтому удаление длинного списка не упирается в лимит контекстов на страницу.

Создавайте `Disintegrator` только в браузере, а не во время серверного рендеринга. Внешние изображения, шрифты и стили должны разрешать CORS или проходить через proxy-опцию движка захвата, иначе они могут не попасть в снимок Canvas.
