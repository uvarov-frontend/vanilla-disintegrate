사용자 효과는 애니메이션 두 개입니다. 하나는 요소를 지울 때, 하나는 되돌릴 때 씁니다. 애니메이션과 사운드는 직접 작성합니다. 라이브러리는 요소를 캡처하고 위치를 재며, 취소와 정리를 맡습니다.

## 플레이그라운드에서 파티클 설정하기

홈 페이지의 플레이그라운드는 삭제와 복원에 각각 독립적인 파티클 및 사운드 설정을 가진 완성된 사용자 효과를 생성합니다. 예를 들어 다음 코드는 `scatter` 삭제와 `vapor` 복원을 결합합니다.

```ts
import Disintegrator, { createParticleEffect, particlePresets } from 'vanilla-disintegrate/snapdom';

const sharedSoundOptions = {
  volume: 0.32,
  playbackRate: 1,
  delay: 0,
  fadeDuration: 0.18,
};

export const disintegrator = new Disintegrator({
  effect: createParticleEffect({
    remove: particlePresets.scatter,
    restore: particlePresets.vapor,
  }),
  sound: {
    remove: {
      ...sharedSoundOptions,
      src: 'scatter',
      reverse: false,
    },
    restore: {
      ...sharedSoundOptions,
      src: 'vapor',
      reverse: true,
    },
  },
});
```

`createParticleEffect()`는 내장 파티클 렌더러를 사용합니다. 플레이그라운드에서 두 단계를 설정하고 생성된 코드를 복사하면 Canvas 또는 WebGL 렌더러를 직접 작성하지 않아도 됩니다. 렌더링 자체를 구현하려는 경우에만 다음 절이 필요합니다.

## 파티클 렌더링 품질 제어

`renderQuality`는 캡처 어댑터와 별개로 내장 WebGL 렌더러의 해상도를 제어합니다. 기본 `auto` 모드는 메모리와 GPU 사용량을 제한합니다. 렌더러의 소스 텍스처는 최대 2,000,000픽셀, 한 변은 최대 2,048픽셀이며 확장된 애니메이션 표면은 최대 4,000,000픽셀입니다.

캡처의 전체 해상도를 유지하는 것이 이러한 소프트웨어 제한보다 중요하면 `exact`를 사용하세요.

```ts
const exactEffect = createParticleEffect({
  remove: { ...particlePresets.vapor, renderQuality: 'exact' },
  restore: { ...particlePresets.scatter, renderQuality: 'exact' },
});
```

직접 예산을 지정할 수도 있습니다.

```ts
const boundedEffect = createParticleEffect({
  remove: {
    ...particlePresets.vapor,
    renderQuality: {
      maxSourcePixels: 4_000_000,
      maxSourceDimension: 4096,
      maxRenderPixels: 8_000_000,
    },
  },
});
```

`exact`는 소프트웨어 다운스케일링을 끄지만 장치의 WebGL 텍스처 및 뷰포트 한계를 우회할 수는 없습니다. 필요한 정확한 표면을 장치가 지원하지 않으면 품질을 조용히 낮추는 대신 `onError`로 오류를 보고합니다. 크기를 알 수 없거나 큰 요소에는 `auto`를 권장합니다. 전체 해상도의 비용은 device pixel ratio의 제곱에 비례해 증가합니다.

## WebGL 컨텍스트 상한 조정

```ts
import { configureParticleContexts } from 'vanilla-disintegrate/snapdom';

configureParticleContexts({ maxContexts: 2, maxIdleContexts: 1 });
```

파티클 렌더러는 페이지 전체에서 한 번에 최대 4개의 WebGL2 컨텍스트를 유지하며, 그중 최대 2개는 효과가 끝난 뒤 재사용을 위해 예열된 채로 남습니다. 이 상한은 효과별이 아니라 페이지 전체 단위입니다. 브라우저 자체가 이미 페이지가 유지할 수 있는 활성 컨텍스트 수를 제한하고, 두 효과가 서로 다른 값을 요청한다면 어느 쪽도 유일하게 옳은 답이 될 수 없기 때문입니다.

페이지가 상한에 도달해 컨텍스트를 얻지 못한 효과는 WebGL2가 전혀 없는 브라우저와 같은 경로를 따릅니다. `remove()`는 요소를 그대로 분리하고 `restore()`는 그대로 드러내며, 작업은 `skipped` 상태로 끝나고 `onError`는 경합이 원인이라고 짚어주는 대신 "애니메이션을 만들지 못했다"는 일반적인 오류를 전달합니다. 어떤 효과든 실행되기 전에 `configureParticleContexts()`를 한 번 호출하면 페이지가 살아있는 동안 이 상한이 바뀝니다. 메모리가 제한된 장치에서는 낮추고, 높일 때는 브라우저 자체가 허용하는 한도까지만 올리세요. 그 이상은 컨텍스트가 버려지는 지점을 옮길 뿐입니다.

## 스냅샷으로 파티클 효과 만들기

아래 예제는 `snapshot`에서 불투명 픽셀을 읽어 Canvas 파티클로 바꾸고 소용돌이를 따라 움직입니다. 이 효과는 스냅샷을 사용하며 `needsSnapshot: true`가 이미 기본값이므로 해당 옵션을 생략할 수 있습니다.

<ParticleVortexSource />

위 코드를 `particle-vortex.ts` 파일로 저장한 다음 `particleVortex`를 가져와 생성자에 전달하세요.

```ts
import Disintegrator from 'vanilla-disintegrate/snapdom';

import { particleVortex } from './particle-vortex';

const effects = new Disintegrator({ effect: particleVortex });

effects.remove(element, { retain: true });
effects.restore(insertedElement);
```

<Demo kind="particle-vortex" />

위 데모와 코드 블록은 같은 파일에서 나옵니다. 돌아가는 그대로가 여러분이 가져가는 것입니다.

`needsSnapshot: false`는 DOM, SVG처럼 픽셀이 필요 없는 대상을 움직이는 효과에 맞습니다. 그 단계는 캡처를 아예 건너뜁니다.

## 스냅샷 없는 코어 사용하기

두 단계 모두 `needsSnapshot: false`라면 `/core`를 가져오세요. 캡처 어댑터, 파티클 렌더러, 내장 오디오가 모듈 그래프에 들어오지 않습니다.

```ts
import Disintegrator, { defineEffect } from 'vanilla-disintegrate/core';

const fade = defineEffect({
  remove: {
    needsSnapshot: false,
    animate: ({ element, layer }) => {
      const visual = element.cloneNode(true) as HTMLElement;
      Object.assign(visual.style, {
        height: '100%',
        inset: '0',
        margin: '0',
        pointerEvents: 'none',
        position: 'absolute',
        width: '100%',
      });
      layer.append(visual);
      return visual.animate([{ opacity: 1 }, { opacity: 0 }], { duration: 240 });
    },
  },
  restore: {
    needsSnapshot: false,
    animate: ({ element, layer }) => {
      const visual = element.cloneNode(true) as HTMLElement;
      Object.assign(visual.style, {
        height: '100%',
        inset: '0',
        margin: '0',
        pointerEvents: 'none',
        position: 'absolute',
        width: '100%',
      });
      layer.append(visual);
      return visual.animate([{ opacity: 0 }, { opacity: 1 }], { duration: 240 });
    },
  },
});

const effects = new Disintegrator({ effect: fade });
```

## 애니메이션 컨텍스트

팩토리가 받는 값입니다.

- `operation` — `remove` 또는 `restore`
- `element` — 요소 자체
- `bounds` — 화면상의 위치, `DOMRectReadOnly`
- `layer` — 그 위치에 이미 놓인 빈 오버레이
- `snapshot` — 캡처된 캔버스 또는 `null`
- `visual` — 스냅샷을 그려 넣은 원본 크기 캔버스, 처음 쓸 때 만들어짐
- `signal` — 작업이 취소되거나 인스턴스가 파괴되면 발동
- `random()` — 이 작업용 난수, 시드가 있어 재현 가능
- `reducedMotion` — 팩토리가 실행되는 동안 항상 `false`; 동작 축소 요청은 호출 전에 작업을 건너뜀
- `addCleanup(fn)` — 여기 등록한 정리는 어떤 결과에도 실행됨

복원 시 `bounds`는 삭제 전 위치가 아닌 **삽입 후 새 위치**를 나타냅니다.

## 반환 값

애니메이션 팩토리는 다음 값을 반환할 수 있습니다.

```ts
type AnimationResult =
  | Animation
  | PromiseLike<unknown>
  | {
      element?: HTMLElement;
      finished: PromiseLike<unknown>;
      duration?: number;
      layoutDelay?: number;
      cancel?(): void;
      dispose?(): void;
    }
  | null;
```

Web Animation, Promise, Canvas나 WebGL 루프, 다른 엔진의 래퍼가 모두 이 계약에 맞습니다. `cancel()`은 재생을 멈추고 `dispose()`는 완료, 취소, 실패 여부와 관계없이 렌더러 자원을 해제합니다.

## 나만의 프리셋 만들기

사용자 `effect`는 기본적으로 무음입니다. 애니메이션과 오디오를 하나의 완성된 선택으로 함께 재사용하려면 완성 프리셋으로 묶으세요.

```ts
import { definePreset } from 'vanilla-disintegrate';

const vortex = definePreset({
  effect: particleVortex,
  sound: {
    remove: { src: 'vapor', volume: 0.35 },
    restore: { src: 'vapor', volume: 0.35, reverse: true },
  },
});

const effects = new Disintegrator({
  preset: 'vortex',
  presets: { vortex },
});

effects.remove(element);
```

내장 프리셋 이름은 루트 및 `/snapdom` 엔트리가 등록합니다. `/core`는 `presets`로 제공하거나 `preset`에 인라인으로 전달한 프리셋만 사용합니다.

## 사용자 사운드

사운드는 시각 단계와 분리하세요. 생성자는 독립된 `remove`와 `restore` 정의를 받으며 사용자 효과가 무음이어야 하면 `sound`를 생략합니다.

```ts
const effects = new Disintegrator({
  effect: particleVortex,
  sound: {
    remove: { src: '/sounds/remove.ogg', volume: 0.35 },
    restore: ({ signal }) => startMyAudioEngine(signal),
  },
});
```

`src`는 내장 이름, `URL`, 로컬 `Blob`/`File`, `ArrayBuffer`, typed-array view 또는 `AudioBuffer`도 받습니다. 오디오 오류는 `onError`로 전달되지만 애니메이션과 DOM 변경은 계속됩니다.
