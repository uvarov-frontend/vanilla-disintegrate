Vanilla Disintegrate 为任意可测量的 DOM 元素添加 **灭霸响指**粒子删除效果。入口 `vanilla-disintegrate/snapdom` 已接好 SnapDOM 截图，且不需要导入 CSS。

## 安装

使用任意受支持的包管理器：

```bash
# npm
npm install vanilla-disintegrate @zumer/snapdom

# Yarn
yarn add vanilla-disintegrate @zumer/snapdom

# pnpm
pnpm add vanilla-disintegrate @zumer/snapdom

# Bun
bun add vanilla-disintegrate @zumer/snapdom
```

库会在元素碎裂前捕获其当前外观，而捕获引擎由你选择。包提供四个可 tree-shaking 的入口：

| 入口                             | 内容                                                                               | 依赖             |
| -------------------------------- | ---------------------------------------------------------------------------------- | ---------------- |
| `vanilla-disintegrate/core`      | 面向自定义效果的生命周期、布局与音频，不包含粒子渲染器和内置声音。                 | 无               |
| `vanilla-disintegrate/particles` | 粒子动画工厂以及四种内置效果的定义。                                               | 无               |
| `vanilla-disintegrate`           | 已配置四种内置效果的 `Disintegrator`；`capture` 由你提供。                         | 无               |
| `vanilla-disintegrate/snapdom`   | 内置效果，并以 [SnapDOM](https://zumerlab.github.io/snapdom/) 作为默认 `capture`。 | `@zumer/snapdom` |

根入口与 `/snapdom` 导出相同的 `Disintegrator` API。`@zumer/snapdom` 是可选 peer 依赖：只有 `/snapdom` 会使用它，其他入口都不会引用它。

`/core` 导出 `Disintegrator`、`defineEffect` 与公共类型。它刻意不提供默认效果：请传入内联效果或已注册的名称。`/particles` 导出 `builtInEffects`、两个粒子动画工厂及其类型，但不会创建实例。高级构建可以只组合所需层；下方的 `captureElement` 代表本页后面介绍的适配器：

```ts
import Disintegrator from 'vanilla-disintegrate/core';
import { builtInEffects } from 'vanilla-disintegrate/particles';

const effects = new Disintegrator({
  capture: captureElement,
  effect: 'dust',
  effects: builtInEffects,
});
```

对于不需要快照的自定义效果，可完全省略 `/particles` 与 `capture`，并在两个阶段设置 `needsSnapshot: false`。

```ts
import Disintegrator from 'vanilla-disintegrate/snapdom';

const effects = new Disintegrator();
const card = document.querySelector<HTMLElement>('.card');

if (card) {
  effects.remove(card, { effect: 'dust' });
}
```

`remove()` 会立即返回操作对象；只有后续逻辑必须等待动画结束时，才需要等待 `operation.finished`。

## 删除并恢复同一个节点

仅当之后可能还需要原节点时才设置 `retain: true`。节点重新插入的位置仍由应用决定。

```ts
const removal = effects.remove(card, {
  effect: 'dust',
  retain: true,
});

await removal.finished;

if (removal.removalId) {
  const retained = effects.take(removal.removalId);

  if (retained) {
    list.append(retained);
    await effects.restore(retained).finished;
  }
}
```

若 `restore()` 未指定新 `effect`，将使用删除时记住的效果对。

## 使用其他捕获库

`capture` 是一个函数：接收元素，返回 `<canvas>` 或其 promise。任何能做到这一点的库都可以接入，例如 `html2canvas`：

```ts
import html2canvas from 'html2canvas';
import Disintegrator from 'vanilla-disintegrate';

const effects = new Disintegrator({
  capture: (element, context) => {
    if (context.signal.aborted) throw new DOMException('Capture aborted.', 'AbortError');

    return html2canvas(element, {
      backgroundColor: null,
      logging: false,
      scale: 1,
      useCORS: true,
      onclone: (_document, clone) => {
        if (context.restoreRootOpacity !== undefined) {
          clone.style.setProperty('opacity', context.restoreRootOpacity, 'important');
        }
      },
    });
  },
});
```

传入的函数会完全替代截图行为。此路径请导入根入口 `vanilla-disintegrate`：它没有强制运行时依赖，SnapDOM 也不会进入模块图。

## 通过 script 标签使用

IIFE 构建已包含 SnapDOM，并全局暴露 `VanillaDisintegrate`：

```html
<script src="/vendor/vanilla-disintegrate.iife.min.js"></script>
<script>
  const effects = new VanillaDisintegrate.Disintegrator();
  effects.remove(document.querySelector('.card'));
</script>
```

若使用内置音频，请把 `dist/sounds` 复制到脚本旁的 `/vendor/sounds`；声音 URL 相对于 IIFE 文件解析。

## 清理

所属页面永久销毁时调用 `effects.destroy()`。它会停止操作和观察器，并释放快照与所有保留的 DOM 引用。

```ts
effects.destroy();
```

## 浏览器支持

核心需要 ES2020 产物、Canvas、Web Animations、`AbortController` 与 `requestAnimationFrame`。四种内置效果使用 **WebGL2** 绘制粒子，因此基线为：Chrome 80+、Firefox 74+、Edge 80+、Opera 67+ 与 Safari 15+。

在缺少 WebGL2 或无法创建上下文时，内置效果会降级而不是报错：`remove()` 仍会移除元素，`restore()` 仍会显示元素，操作以 `skipped` 状态结束，原因通过 `onError` 传出。基于 WAAPI、CSS 或 Canvas 2D 的自定义效果在旧引擎上照常播放。

每个运行中的内置效果只占用一个 WebGL2 上下文，并在操作结束时立即释放，因此删除长列表也不会触及浏览器的每页上下文上限。

只在浏览器中创建 `Disintegrator`，不要在服务端渲染期间创建。跨域图片、字体与样式表必须允许 CORS，或通过捕获适配器的代理选项加载，否则可能不会出现在 Canvas 快照中。
